## 这一阶段最终要做到什么

完成 **P1：机械臂运动与数据记录实验台**。围绕同一个简化两关节机械臂逐步积累：

`Python 数据与曲线 → ROS 数据传递 → FK 与模型显示 → 雅可比/IK → 仿真与反馈控制 → 带时间轨迹 → 记录回放与系统解释`

期末能独立解释输入输出、修改一个参数或目标、重跑结果并分析一次失败。ROS 控制接口另用官方 RRBot 示例验证，动力学控制通过自己记录的数值/物理仿真结果验证。

每周一个核心成果。资料阅读、代码实践和结果验证围绕这个成果展开；当前不要求先通读所有目录。

## 时间与推进规则

- 每周总预算 10—12 小时，核心任务约 8 小时：理论约 2 小时、实践约 5 小时、验证与记录约 1 小时；其余为机动。
- 共 10 个主题学习周、2 个缓冲周、1 个结项周。核心预算约 104 小时，包含缓冲与结项；这是工作量预算，不是考勤。
- 日期是基准进度。已有能力直接通过当周验收后可以提前推进；连续超时就缩小范围，保留关键验证。
- 每次学习结束保存运行命令、当前结果、卡点与下一步。下次从复跑上次结果开始。
- 真机、GPU训练和实验室排期都不是本阶段的完成前提。实验室同类工作有个人理解与证据时可抵扣。
- 下列“完成”指本页约定的入门深度；各目录中的“必须掌握”是到本科毕业的总体目标。

每周先用一到两小时定位概念，尽早转入自己的例子。下面的章节/标题用于定位，完整教材和所有教程都不作为本阶段清单。网页版本与安装版本对应；Modern Robotics 的二维实现采用本计划的简化推导，遇到依赖旋量的完整六维证明先留后续。

<a id="src-python"></a>

### Python

[Python 官方教程](https://docs.python.org/3/tutorial/)：函数、Modules、Input and Output、Errors and Exceptions；Classes 只读现用基础。按缺口选读，不整本重学。

<a id="src-numpy"></a>

### NumPy

[NumPy 初学者指南](https://numpy.org/doc/stable/user/absolute_beginners.html)：创建数组、shape、索引、广播、基本运算、数组保存；矩阵运算结合 W03/W06。

<a id="src-plot"></a>

### 绘图

[Matplotlib Pyplot 教程](https://matplotlib.org/stable/tutorials/pyplot.html)：plot、坐标轴标签、图例、子图、保存图片。只为实验画清楚结果。

<a id="src-tools"></a>

### Linux/Git

[Missing Semester](https://missing.csail.mit.edu/) 选命令行、环境、调试；[Pro Git](https://git-scm.com/book/zh/v2) 选工作区/暂存区、提交、分支、合并与回退。

### C++

[LearnCpp](https://www.learncpp.com/) 按标题查 const、references、pointers、classes、std::vector、smart pointers；先读懂 W05 实际代码，课程其余内容以后补。

<a id="src-ros"></a>

### ROS 2

[Jazzy 教程](https://docs.ros.org/en/jazzy/Tutorials.html)：Beginner CLI 的节点/话题/参数/服务/动作/录包；Client libraries 的工作空间、包、Python/C++ 发布订阅、参数；Intermediate 只选 Launch、URDF、TF2。站点访问受限时可查[官方教程目录源码](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials.rst)与[客户端教程列表](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries.rst)。

### 机器人学与控制

[Modern Robotics 教材](https://hades.mech.northwestern.edu/index.php/Modern_Robotics)与[配套视频](https://modernrobotics.northwestern.edu/nu-gm-book-resource/)：第 2 章配置/任务空间；第 3 章旋转与齐次变换；第 4—6 章选 FK、雅可比和数值 IK 的概念及相关例子；第 8 章先读动力学各项的物理含义；第 9 章点到点轨迹；第 11 章先读误差响应和单关节反馈，力矩输入下 PID 对应 11.4 的单关节部分。每次阅读为当周二维例子服务，空间旋量、六维推导与整章习题以后再展开。

## 怎样判断“有进展”并处理落后

每个主题周的完成依据是：**有可复跑成果、做过一次独立修改/对照、能解释观察到的结果**。阅读和照着示例跑通可以记录为“进行中”，有证据后标记“已验收”。

- 开始困难时，只做一个启动动作：打开上次记录、运行已有命令、改一个参数。随后再选择本次要完成的小步骤。
- 环境问题卡住约两小时，就保存错误、版本和已尝试步骤并求助；暂时完成可独立推进的数学/数据部分，环境验收保留为待办。
- 某周不足 10 小时时优先保留核心产出与验证，剩余内容移到缓冲。连续两周落后时，缩小例子或删选做项，重新估计日期。
- 提前通过时可以进入下一周或整理结果；缓冲周可以休整。
- 每周反馈给导师式助手时只需四项：周次、成果/运行方式、你自己的解释、当前卡点。助手优先给提示、审查与验证建议，练习实现由你完成。

## 第一阶段结束的最低证据

1. 工程：别人能根据说明运行核心例子；你能独立改一个参数并定位一次错误。
2. 系统：能画出节点/模型/控制器/硬件接口和反馈关系，说明话题与动作的作用。
3. 运动学：FK 与雅可比有交叉验证；IK 有收敛与失败记录。
4. 控制：存在稳定复跑的跟踪例子，保存参考/反馈/误差，并完成一个单变量对照。
5. 集成：目标、轨迹、仿真结果、数据记录与模型回放可以串起来，明确实时与离线边界。
6. 交接：列出下一阶段需要的相机坐标、标定、碰撞规划接口；有条件时阅读实验室现有平台如何对应这些模块。

这些证据齐备后进入第二阶段。PyTorch 选做、复杂 C++、高级控制和真机窗口不作为额外门槛。
