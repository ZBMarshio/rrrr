<a id="chapter-intro"></a>

## 本章导读

**为什么学这一章。** 算出一个目标关节姿态之后，还要决定怎样过去、怎样跟踪、遇到偏差和接触怎样响应。这章把几何目标接到随时间变化的实际运动。

**学完会有什么变化。** 学习前，机器人没有按预期到达时可能只想到调增益；学习后，你能区分参考、输入、反馈与约束，检查路径、时间、控制和执行分别承担什么责任。

**接下来能做什么。** 可以在简单模型里验证反馈控制与轨迹，再接碰撞规划和末端到达。接触控制、MPC等作为后续入口，现阶段先保留一条能解释误差的执行链。

## 学习内容与掌握层次

| 层次 | 内容 |
|---|---|
| 必须掌握 | 反馈与离散 PID；采样、噪声、饱和、积分累积和延迟；位置/速度/力矩接口；关节轨迹与基于 IK 的末端运动；路径/轨迹区别、速度加速度约束、碰撞和停止条件。 |
| 了解即可 | RRT/PRM；阻抗、导纳与力控制的区别和接口条件；前馈、重力补偿、基础 MPC。 |
| 以后深入 | 操作空间控制、混合力位控制、最优控制、复杂 MPC、全身控制与多接触控制。 |

<a id="route"></a>

## 学习路线

1. 先在单关节或简化模型上实现离散 PID，用实际曲线理解采样与饱和。
2. 加入平滑轨迹、限位和 IK 末端运动；学习碰撞约束，再使用规划框架。
3. 通过一维接触仿真理解阻抗/导纳；需要真机力控制时再核对传感器、接口与控制周期。

## 理论、代码与可验收成果

| 类型 | 当前要求 |
|---|---|
| 理论学习 | 理解误差反馈、控制接口、路径与时间参数化，以及接触时的力位关系。 |
| 代码实践 | 实现简单 PID、轨迹插值和跟踪记录；用现成规划器处理带障碍场景。 |
| 小项目/验收 | 一份不同参数/采样周期的跟踪对照报告，以及可复跑的轨迹执行或规划例子。 |

无真机替代：NumPy 简化动力学、MuJoCo 单关节/机械臂；MoveIt 配合 mock hardware 检查规划接口。

成果尽量复用到总路线的项目版本中；运行成功、指标验证和硬件验证分别记录。
