## 第 1 题

一种记录模板，不是对现有实验室设备的事实声明：

```text
接口类型与入口：
动作语义：absolute position / delta position / velocity / torque：
joint_names 与顺序：
单位、零位、范围、缩放：
增量相对基准与累计规则：
参考时刻、控制/发送周期、时间戳：
下层控制器与缓冲/替换策略：
状态来源、采样时间与完成条件：
超时、拒绝和停止行为：
已由源码确认 / 已实际运行确认 / 未知：
```

保持与数据集/策略动作定义一致；不能把 action 和 observation.state 因形状相同就视为相同语义。

<a id="ex2"></a>

## 第 2 题

零位置要求去关节零位，可能产生运动；零速度是速度参考，在相应内环正常工作等前提下才有相应行为；零力矩不抵消一般重力或外力。

上游停止发布后，控制器可能仍执行已有轨迹，驱动可能保持最近命令。具体超时/取消/保持由各层协议确定，不能跨平台推断。

<a id="ex3"></a>

## 第 3 题

绝对位置是目标 0.1 rad，尚未证明实际到达；速度参考按理想积分持续 0.02 s 得参考增量 0.002 rad，实际仍需看执行。

力矩初始加速度为 0.1/0.05=2 rad/s²。随后速度增加，阻尼会影响加速度，不能一直按初始加速度积分并当成精确结果。

<a id="ex4"></a>

## 第 4 题

给每个箭头附输入/输出和具体文件。位置 command interface、轨迹 positions、驱动位置目标可形成一条链；但上层提供 time_from_start，不表示驱动也使用该字段。

软件配置的 update_rate 是期望配置，真实周期和机械到达时间需测量。能说明两者边界，就是本题的主要验收。
