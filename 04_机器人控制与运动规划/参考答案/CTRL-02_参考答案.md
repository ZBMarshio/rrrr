## 第 1 题

正确积分 0.1 rad·s，直接累加为 10，差了周期因子且单位也不对。0.005 s 时 200 次更新，正确积分仍为 0.1 rad·s。

CTRL-01 模型每 h 推进一次，但控制积分每 control_steps*h 更新一次。实际控制若有抖动，记录真实间隔并按选定实现处理。

## 第 2 题

参考函数可以是：

```python
def switching_reference(t):
    return (2.0 if t < 1.0 else 0.0), 0.0
```

这里的 D 采用速度反馈，未把位置阶跃当作有限参考速度。比较完全相同模型与条件，不能只在抗饱和那组扩大力矩限幅。

检查条件积分的局部反例：旧 integral=1、error=1、dt=0.1、Kp=1、Ki=2、Kd=0、limit=1，抗饱和时应拒绝继续增长；误差反向且有助解除饱和时允许积分回退。

抗饱和从起点就开启与中途才开启，初始积分状态可能不同，实验需说明。

## 第 3 题

control_steps=1/5/20 对应 0.001/0.005/0.02 s 控制周期。第二组固定 0.005 s，delay_ticks=10 即延迟 0.05 s。

在 FIFO 教学模型中记录 u_cmd 与 u_applied，验证延迟。它只模拟命令延迟，没有建模所有传感延迟、网络抖动和丢包。

性能不保证对某一周期严格单调；若失败，保留参数、曲线与退出信息，不靠继续增益来掩盖原因。

## 第 4 题

理论速度噪声约 0.282843 rad/s。一个一阶低通递推为：

```text
alpha = exp(-2*pi*cutoff_hz*dt)
filtered[k] = alpha*filtered[k-1] + (1-alpha)*raw[k]
```

这是从连续一阶极点得到的一种离散系数选择，说明初值、带宽和 dt；噪声统计有限样本不会精确等于理论值。比较无噪声基准的幅值/相位/误差，平滑外观不代表真实速度更准确。
