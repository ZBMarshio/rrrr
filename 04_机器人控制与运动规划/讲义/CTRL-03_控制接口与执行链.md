# CTRL-03：先问输出是什么量，再谈怎么控制

[学习指南](../学习指南.md) · [知识索引](../知识索引.md#ctrl-03) · [提示与答案](../参考答案/CTRL-03_参考答案.md)

## 导读

**为什么学这一节。** 角度、速度和力矩都可能写在同样形状的action数组里。先确定输出的物理含义，控制公式才知道该接到哪里。

**学完会有什么变化。** 从按变量名猜作用，进到能沿应用、控制器和驱动核对单位、闭环位置和时间参数，说明谁负责修正误差。

**接下来能做什么。** 可以检查[ROS-08](../../02_ROS2与机器人系统/讲义/ROS-08_ros2_control与执行接口.md#intro)的接口配置，为[SIM-06](../../06_仿真与系统集成/讲义/SIM-06_模型与接口适配.md#intro)做数据适配，也能验证[LEARN-01](../../08_机器人学习与具身智能/导读.md#learn-01)中的策略动作是否与平台一致。

## 同一个数字，在不同接口中含义不同

| 接口 | 常见量纲 | 还需确认 |
|---|---|---|
| 绝对关节位置 | rad 或 m | 零位、关节顺序、内环、到达/替换策略 |
| 增量位置 | rad 或 m 的增量 | 相对当前测量还是上次参考、更新周期、累计方式 |
| 关节速度 | rad/s 或 m/s | 积分/伺服位置、超时、限速 |
| 力矩/力 | N·m 或 N | 动力学、重力、执行器与低层限制 |

维度为 2 的数组不能告诉你是哪一种，名称叫 action 也不能。需要沿参数、类型、控制器配置和驱动继续追踪。

## 控制环可能在不同层

应用发位置参考时，下层位置伺服可能负责快速闭环；应用自己输出力矩时，上层就要承担相应动力学控制。把本章力矩 PID 的输出原样当成角度发送，既改变单位也改变整个闭环。

时间参数也分层：应用发送周期、轨迹参考到达时刻、控制器更新周期、驱动周期、实际反馈时刻，各自测量与解释。

## 练习

<a id="ex1"></a>

### 第 1 题：为一条命令写契约。约 20 分钟

给两关节 action 写明：绝对/增量/速度/力矩，关节名顺序、单位、归一化与反归一化、周期、限幅、参考基准与反馈来源。

未知项写未知，并说明去哪个文件/接口找，不能用数组形状猜测。

<a id="ex2"></a>

### 第 2 题：发 0 等于停止吗？约 15 分钟

分别解释零位置、零速度、零力矩的可能含义。竖直摆在非平衡位置收到零力矩，是否保持原位？

复用第二章停止例子，指出上游不再发送后，下层可能还保存什么。

<a id="ex3"></a>

### 第 3 题：相同 0.1 的三种解释。约 20 分钟

当前 q=0，若输入是绝对位置 0.1 rad、速度 0.1 rad/s 持续 0.02 s、力矩 0.1 N·m，分别能直接得出什么？

对水平单关节模型，初始 qd=0、无负载，求该力矩的初始角加速度；不要把它称为已经完成的角度变化。

<a id="ex4"></a>

### 第 4 题：阅读一条现成执行链。W11 约 25 分钟

从 launch/参数 → 控制器 YAML → ros2_control 接口 → 插件/驱动 → 状态反馈，标出每层的量与单位。使用官方模拟示例或授权可读代码，不为此启动真实驱动。

已有第二章链路说明时复用，补控制周期、缓冲和完成条件，区分源代码证据与实际测量。

## 直觉与回顾

接口是一张关于“这个数字代表什么”的约定。先把约定读对，才能判断控制律是否合适。

复盘挑一个你曾笼统称作“控制机器人”的调用，重新说清它实际只给了哪一层、什么参考，以及谁在闭环。
