## 导读

**为什么学这一节。** IK给出的关节解只是执行链的一个中间结果。想知道工具最终到了哪里，还要经过轨迹、控制与反馈。

**学完会有什么变化。** 从用期望关节值计算位置并宣布到达，进到能同时记录目标、参考和实际状态，用反馈FK评估真实的后端结果。

**接下来能做什么。** 可以串联已有FK/IK与控制，形成P1的最小到达实验，再用[VIS-06](../../05_机器人感知与视觉/讲义/VIS-06_手眼标定与坐标闭合.md#intro)产生的空间目标驱动同一条链。

## 资料与本期范围

复用第三章 [KIN-06 IK](../../03_机器人学基础/讲义/KIN-06_解析与数值IK.md)与 [KIN-05 雅可比](../../03_机器人学基础/讲义/KIN-05_雅可比与局部运动.md)。先读自己的第三章函数与失败记录，再按问题查 Modern Robotics 第 6、9 章。

## 一条执行链上有不同的对象

`x_goal → q_goal(IK) → q_ref(t) → 控制接口 → q_actual(t) → FK(q_actual)`

- x_goal 要写坐标系、单位、TCP，以及只约束位置还是也约束姿态。
- IK 解只证明某个配置满足其求解问题，还要检查限位、残差与成功原因。
- 关节轨迹给出期望随时间怎样变化。
- 末端实际误差由实际反馈的 FK 得到。使用 q_ref 做 FK 得到的是期望末端位置。

本章平面 2R 位置 IK 只有两个任务维度，不能同时随意指定完整三维姿态。

## 两种“直线”

关节线性路径一般对应弯曲 TCP 路径。若要求 TCP 沿两点间直线，需要生成笛卡尔路径点、逐点求 IK，并检查分支、关节变化、约束与碰撞。

上一点解作为下一点初值，能帮助保持局部连续性，但不是保证。奇异附近、限位、路径穿过不可达区都可能失败；仅验证有限路径点也不保证中间连续路径有效。

## 选读：基于速度的末端伺服

一个局部结构是 `qd_ref=J#(xd_ref+K(x_ref-x_actual))`。J 与误差的坐标系、线速度的参考点、维度必须一致；K 在这一写法中单位为 1/s。

得到关节速度参考后，还需要明确速度接口，或积分生成位置参考并交给内环。伪逆、阻尼、速度限幅、奇异性与内环带宽都是条件；不能把计算出的 q_ref 当作实际状态更新。

## 练习

<a id="ex1"></a>

### 第 1 题：为 W10 画一条可验收的链。约 20 分钟

沿用第三章可达目标与求解器，写出目标坐标系、IK 结果、轨迹接口、实际反馈来源和结束条件。指出 q_goal、q_ref、q_actual 哪些量可以相同，哪些量必须独立记录。

无机器人时，允许使用数值模型反馈；双关节各用单关节模型时，明确忽略了耦合动力学。

<a id="ex2"></a>

### 第 2 题：关节直线是否为末端直线？约 30 分钟

L1=0.3 m、L2=0.2 m，q_start=[-0.8,1.2]、q_end=[0.8,0.6] rad。在两关节间插值 101 点并 FK，计算每点到两个末端端点所构成线段的距离。

画 TCP 路径，报告最大偏离。这里暂不放障碍，不把几何结果当作控制误差。

<a id="ex3"></a>

### 第 3 题：沿笛卡尔直线求解并检查。约 40 分钟，第二阶段补

连接上一题的两个 TCP 端点，采样 101 点。复用 KIN-06 的 solve_ik_position，用前一点解热启动；限位 lower=[-1.6,-2.4]、upper=[1.6,2.4]。

记录每点残差、失败位置与相邻关节变化；按假设的采样时间求速度并检查。失败时返回已经得到的部分结果和原因，不能把失败解继续当成功轨迹。

<a id="ex4"></a>

### 第 4 题：用雅可比核对速度。约 20 分钟，选做

在 q=[0,π/2]，希望 TCP 瞬时速度 [0.02,0] m/s，计算关节速度。对照 FK 小步差分，说明该结论为何只在局部成立。

如果软件接收位置参考，你还缺哪一步？如果没有实际反馈，误差闭环是否成立？

## 直觉与回顾

IK 像告诉你“终点可以采取什么姿势”，轨迹安排“怎样逐步走过去”，控制器根据实际情况不断纠正。它们各解决一部分问题。

复盘选一处末端误差，先判断来自目标/坐标、IK 几何、时间安排还是执行跟踪，再决定下一步改什么。
