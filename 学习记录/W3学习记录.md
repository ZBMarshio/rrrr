### 读到什么
- 通常使用np.array创建numpy数组，创建的对象有ndim（维数，也叫轴数）、shape（行数和列数）、size（总数）三个主要属性
- 维数，也叫轴数，在二维数组中，“第0轴”指行、说“第1轴”指列
- 对数组切片之后再修改切片中的数字，可以看到原数据也发生了变化
- 广播规则：两个数组运算时，从**最后一维**开始往左逐维比较；每一维相等，或其中一方是 1，才可广播（比如（1,2,3）中，3就是最后一轴）
### 我的理解
- 关于 shape：`np.array([1,2,3])` 是 `(3,)` 一维；`np.array([[1,2,3],[4,5,6]])` 是 `(2,3)` 二维，外层是第 0 轴；`np.newaxis` 可在指定位置插入长度 1 的轴
- ":"的用法参考的还是python的用法
- `q[:, 0]` 用整数索引取第 0 列，维度被消掉，得 `(4,)`；`q[:, 0:1]` 用切片取同一列，但保留列维，得 `(4, 1)`。区别在“整数索引 vs 切片”，不在 0 这个数字

### 读到什么
- 用 axis 指定沿哪一维聚合；二维数组沿一个轴聚合会降成 1 维（加 `keepdims=True` 可保留成 (1,2) 或 (4,1)）
- 基础索引（切片）产生**视图(views)**，高级索引（整数列表、布尔掩码）产生**副本(copies)**：视图与内存共享，改视图会改原数据；副本独立。`base` 属性可用来验证：视图的 base 指向真正持有内存的那个数组（可能不是紧邻的父数组），副本的 base 为 `None`
- `np.diff()` 一阶差分定义为 `out[i] = a[i+1] - a[i]`，结果比输入少一个；位置序列的差分是**位移增量**（单位 m），再除以 `dt` 才是速度（m/s），对速度再差分并除以 `dt` 才是加速度（m/s²）
### 我的理解
- 对数组使用类似isfinite、isnan的函数，需要加上.any()或者.all()
- 必须学会使用None == np.newaxis时的用法，用于新增一个轴，增加时根据shape的位置增加轴
- 差分计算需要指定好轴，默认指定axis=-1也就是最后一轴，可能会导致错误
