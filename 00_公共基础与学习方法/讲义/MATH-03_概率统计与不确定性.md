# MATH-03：先说清楚在对哪些样本求平均

[学习指南](../学习指南.md) · [索引](../知识索引.md#math-03) · [提示与答案](../参考答案/MATH-03_参考答案.md)

<a id="intro"></a>

## 导读

**为什么学这一节。** 平均误差很小，可能是正负抵消；记录很多帧，也可能只重复了同一个回合。统计量要先和样本来源一起理解。

**学完会有什么变化。** 从用一个平均数代表全部结果，进到能区分偏差、误差大小、波动和条件概率的分母，知道重复的是帧、回合还是训练。

**接下来能做什么。** 可以给控制或训练结果写清统计单位与波动，为[EXP-02](EXP-02_指标基线与消融.md#intro)的评测和[RL-01](../../08_机器人学习与具身智能/导读.md#rl-01)的随机交互建立基础。

## 资料与范围

选读 [MML](https://mml-book.github.io/) 第6章的概率、条件概率、期望、方差与高斯分布；API 查 [NumPy 1.26 std](https://numpy.org/doc/1.26/reference/generated/numpy.std.html)。本科前期先掌握计数与描述统计；置信区间、贝叶斯推断、严格检验以后深入。

## 四个常见混淆

误差的平均值可反映偏差，MAE/RMSE 反映误差大小，标准差描述围绕均值的波动。单位都要写清：方差是原单位平方，标准差回到原单位。均值为零不等于没有误差。

NumPy std 默认 ddof=0，分母 N；估计样本方差常用 ddof=1，分母 N−1。样本标准差本身不是均值置信区间；三次训练也不自动足以证明方法稳定。

同回合的 1000 帧和 1000 个独立回合不是相同证据。先决定统计单位是帧、episode、训练 seed，还是采集 session，再解释波动。

条件概率改变了分母：P(检测阳性|确有目标) 与 P(确有目标|检测阳性) 不同。机器人学习里 P(action|observation) 也要说清条件与输出，不能把各种分数都当成功概率。

## 练习

<a id="ex1"></a>

### 第1题：平均零仍有误差。约15分钟

两次误差为 +3 mm、-3 mm，求均值、MAE、RMSE、总体标准差、样本标准差。哪些量单位是 mm，哪些是 mm²？

<a id="ex2"></a>

### 第2题：重复实验的描述。约20分钟

三个预定训练 seed 的成功率为 [0.6,0.8,0.7]。计算均值与样本标准差。若每个 seed 又含20次任务，为什么不能无说明地把它们当作60个独立训练实验？

<a id="ex3"></a>

### 第3题：样本单位。约20分钟

10个采集回合，每回合1000帧，比较按帧均值和先按回合求指标再平均。若回合长度不同，两种结果可能怎样变化？只重复一个回合能测未见场景泛化吗？

<a id="ex4"></a>

### 第4题：用计数检查条件概率。约20分钟

1000张图中100张有目标；检测到90张真实目标，同时在900张无目标图中误报90张。计算召回率、检测阳性中的真实比例。两个90为什么不能都解释成“90%可靠”？

## 直觉与回顾

平均值把一堆结果压成一个数，压缩时会丢掉顺序、失败与分组信息。统计之前先画原始点或看各组，通常更容易发现自己问错了问题。

复盘：你的“重复十次”到底重复了初始化、任务初态、对象还是同一段日志？
