# EXP-01：验证集在替你问哪个问题

[学习指南](../学习指南.md) · [索引](../知识索引.md#exp-01) · [提示与答案](../参考答案/EXP-01_参考答案.md)

<a id="intro"></a>

## 导读

**为什么学这一节。** 模型在验证集上很好，换一个物体却失败，可能是考题与目标不同。划分数据时就要决定自己要测哪种泛化。

**学完会有什么变化。** 从随机分文件，进到按回合、物体或场景核对来源，发现共享帧、未来信息和预处理统计量中的泄漏。

**接下来能做什么。** 可以检查标定或策略数据的划分，再用[ML-05](../../07_机器学习与深度学习/讲义/ML-05_过拟合泄漏与排错.md#intro)定位训练与实际效果之间的差距。

## 资料与范围

选读 [MML](https://mml-book.github.io/) 第8章关于模型、数据与选择的讨论；训练流程对照 [PyTorch Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)。完整神经网络泄漏演示复用第七章 ML-05，本节先在 ID 和统计量层面检查。

## 把三种用途分开

train 用来拟合参数/预处理；val 用来选择模型、阈值或超参数；test 留到方案冻结后报告结果。反复根据 test 调整，test 就参与选择了，需要新的独立评测来支持最终结论。

划分单位由目标决定：新帧、新回合、新场景、新物体是不同问题。按文件随机分并不能自动隔离同一来源；裁剪、复制、相邻帧与时间窗都可能共享原始信息。

先分来源组，再做切窗/增强。均值、尺度、数据驱动筛选规则只在 train 拟合；固定的仪器单位换算与用数据估计参数是不同情况，应写清来源。

在标定中，留出的新图像/新姿态可检查预测一致性；如果它与训练仍共享同一装置，不能因此宣布对新相机安装也有效。具体几何验证回第五章。

## 练习

<a id="ex1"></a>

### 第1题：选择划分单位。约20分钟

你要测试“换物体后能否操作”，数据有 object_id、episode_id、frame_id。仅按 episode 划分够吗？如果目标只是在同物体上换回合，问题又有何不同？

<a id="ex2"></a>

### 第2题：预处理会隐藏什么。约20分钟

train=[[1],[3]]、val=[[101],[103]]。用 train 的均值和总体标准差标准化两者；再分别用各自统计量处理。哪种会隐藏验证分布的整体偏移？

<a id="ex3"></a>

### 第3题：检查来源交叉。约20分钟

写 group ID 交叉检查。用 train=[A,B]、val=[C]、test=[D] 通过；再把 B 放到 val，要求明确报错。解释这个检查为什么无法证明 group 定义本身合理。

<a id="ex4"></a>

### 第4题：时间窗与未来信息。约25分钟

训练窗使用原始帧 [0,1,2]，验证窗使用 [2,3,4]。仅比较窗口文件名会漏掉什么？若输入本应是 t 之前观测，却包含 t+1 的状态，又是什么问题？分别提出修正。

## 直觉与回顾

验证分数要和它问的问题一起读。先说明“换了什么、保留了什么”，你才知道这个分数能帮助哪一个决定。

复盘：你的测试集合有哪种来源信息从未出现在训练和模型选择里？
