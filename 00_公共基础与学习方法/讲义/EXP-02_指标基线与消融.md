# EXP-02：改动有效，需要一个可以比较的参照

[学习指南](../学习指南.md) · [索引](../知识索引.md#exp-02) · [提示与答案](../参考答案/EXP-02_参考答案.md)

<a id="intro"></a>

## 导读

**为什么学这一节。** 改完代码后结果更好看，怎样判断这次修改有没有帮助？需要一个固定的参照和事先说明的指标。

**学完会有什么变化。** 从只展示最好的一次，进到能写清基线、误差单位、成功分母和失败，并识别同时改变多个条件造成的解释困难。

**接下来能做什么。** 可以比较两种校正或控制配置，也能按[LEARN-07](../../08_机器人学习与具身智能/导读.md#learn-07)组织学习方法的对照实验和结果报告。

## 资料与范围

统计定义复用 MATH-03，模型比较查 [MML](https://mml-book.github.io/) 第8章。控制与闭环任务分别回第四章、第六章的固定试验评测；本节先写比较协议。

## 在运行之前决定怎样算

先列任务、试验 ID、成功条件、误差单位、结束时刻/窗口、失败类型与分母。平均位置误差不能自动代表成功率；到达后剧烈振荡也不一定满足“稳定到达”。

基线回答“当前做法比什么好”：零校正、传统方法、简单模型、随机/固定策略等应与任务匹配。消融拿掉一部分，看该部分在固定条件下的作用；一次只改一项可以让解释更明确，但不自动证明因果机制或排除所有混杂。

贯穿例子比较三种校正：直接使用读数；只减训练偏置；拟合增益+偏置再反解。使用同一留出数据、相同单位和指标。只改模型形式时，数据与评价规则保持相同；选择看 val，test 在冻结后报告。

## 练习

<a id="ex1"></a>

### 第1题：误差的几种压缩。约20分钟

e=[0.003,-0.003,0.006] m，求平均有符号误差、MAE、RMSE 和最大绝对误差。哪一项会被正负抵消？写函数拒绝 NaN 和长度不匹配。

<a id="ex2"></a>

### 第2题：成功率的分母。约20分钟

四个预定且均已尝试的任务：两成功、一执行超时、一输入被拒绝。后三者中超时有最终误差、被拒绝没有。求成功率与有效误差数，解释为什么不能删掉被拒绝任务后报告。

<a id="ex3"></a>

### 第3题：校正基线与消融。约35分钟

用本章 CSV 的 train 拟合零校正、偏置校正和完整仿射校正，先看 val 决定报告方案。冻结后对 test 用相同指标评测。说明完整模型哪一部分对应偏置、哪一部分对应比例误差；不要把 test 当调参依据。

<a id="ex4"></a>

### 第4题：一次混杂的比较。约20分钟

A 模型用100条示教、1万次更新；B 模型用1000条示教、10万次更新，B 指标更好。可以得出什么？设计一个更接近“结构本身是否有帮助”的对照，并列出仍需说明的预算差异。

## 直觉与回顾

基线让变化有参照，失败记录让参照完整。一张图最有用的部分，往往是它让你知道下一次该改变哪一个条件。

复盘：如果只允许再做一个实验，哪一个最能区分你现在的两种解释？
