# EXP-05：给下次开始留一条清楚的路

[学习指南](../学习指南.md) · [索引](../知识索引.md#exp-05) · [提示与答案](../参考答案/EXP-05_参考答案.md)

<a id="intro"></a>

## 导读

**为什么学这一节。** 实验室插单或一周忙碌之后，最耗力的往往是重新想起上次做到哪。给下次开始留清楚的入口，投入才能接续。

**学完会有什么变化。** 从按看过多少内容记进度，进到按自己能解释、修改和验证的成果记录，并能把大任务缩成当前可完成的一步。

**接下来能做什么。** 可以写恢复卡、抵扣实验室同类成果，逐步把P1/P2与后续学习实验整理成有个人贡献的项目经历。

## 资料与范围

复用第一章的工程记录、EXP-03 配置与第六章实验复位；本节提供个人学习的操作约定，不增加软件依赖。训练程序状态恢复看第七章，个人任务恢复与 checkpoint 是两个层次。

## 用成果管理进度

每周10—12小时中先安排约8小时核心成果，留2—4小时应对调试、补缺口和临时任务；核心成果可以是“一次雅可比检查”或“一份标定留出验证”，而非填满阅读页数。

学习状态分开记：看过、能解释、跟着运行、独立修改验证。已经会的内容用小题与已有证据抵扣。短周保留一次20—30分钟的复跑/记录整理；恢复时重新估算剩余工作，不把欠下的阅读机械叠加。

实验室任务与个人任务分别写目标和证据，满足相同验收项的部分可以抵扣。实验室临时训练并不自动覆盖坐标、标定或控制知识；个人项目也不依赖临时任务恰好对齐。

## 中断前保存五件事

当前目标；代码/数据/配置位置与版本；实际运行方式和已有结果；卡点与尚未验证项；下次第一步及其预期。第一步要具体到能立即动手，例如“用保存的第3组输入重跑，核对时间戳”，而不是“继续学习机器人”。

项目证据分层：数学/局部数值，接口与离线回放，物理仿真，真机。每层都可以形成成果，但“消息发出”“模型动了”“任务成功”需要各自证据。作品集写清个人实现、使用的现成组件与验证条件。

## 练习

<a id="ex1"></a>

### 第1题：恢复卡。约15分钟

为当前任务写一张恢复卡，包含文件位置、成功运行入口、最后结果、卡点、下次第一步。找出哪一项如果只写“见聊天记录”，仍不能直接恢复。

<a id="ex2"></a>

### 第2题：把一周缩小。约15分钟

原计划8小时核心任务，本周只剩3小时。把任务缩成一个可验收成果，指出延后的扩展和恢复入口。怎样保留连续性而不承诺周末补完全部内容？

<a id="ex3"></a>

### 第3题：实验室任务抵扣。约20分钟

你为实验室处理了一批 VLA 数据并运行训练。分别检查它是否证明数据划分、单位/时间、模型恢复、标定与传统控制能力。列出可抵扣项和仍需补的证据。

<a id="ex4"></a>

### 第4题：写一条可信的项目经历。约20分钟

假设你完成 FK/IK、仿真轨迹跟踪和日志评测，没有真机窗口。写问题、个人贡献、关键结果和验证范围；再列下一项改进。不把作者提供的参考图直接当作个人成果。

## 直觉与回顾

沉下心常常需要一个足够小、做完能看见结果的动作。记录让今天的投入能被明天接住，基础也就在这些可解释的结果里逐渐连起来。

复盘：如果明天临时插单，你现在能留下哪几行文字，让下周少花半小时重新进入状态？
