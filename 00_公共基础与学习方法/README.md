## 本章导读

**为什么学这一章。** 做机器人项目时，常会遇到公式能抄下来、结果却解释不清的时刻。这章把数学和实验方法接到具体疑问上：一组坐标怎样变换，误差为什么放大，一次好结果到底说明什么。

**学完会有什么变化。** 学习前，遇到抽象概念可能只能继续查更多资料；逐步学会后，你能把问题缩成一个有单位、有输入输出的小例子，再用手算、代码和对照检查自己的理解。

**接下来能做什么。** 可以给当前工程写一份可复查的实验记录，在IK、标定或训练中按需补数学，也能在任务中断后接着推进。从自己正卡住的一个问题进入即可。

## 学习内容与掌握层次

| 层次 | 内容 |
|---|---|
| 必须掌握 | 线性代数与坐标基；导数、梯度和链式法则；概率、均值方差；最小二乘与数值误差；数据划分、基线、日志、复现。 |
| 了解即可 | SVD、伪逆和条件数的含义；置信区间；基础约束优化；实验中的混杂因素。 |
| 以后深入 | 流形优化、概率推断、系统辨识、严格统计推断；根据研究问题选择。 |

## 前置与衔接

- 前置：从已有 Python 与高中/大学数学基础出发；遇到缺口时只补当前任务所需内容。
- 去向：与 01—08 并行推进；数学概念在运动学、标定、控制和学习算法中反复应用。
- 层次表示毕业前与研一的深度边界；先通过小练习检查，已掌握的部分跳过。

## 学习路线

1. 先检查矩阵运算、坐标基、导数和数组维度，在小型 NumPy 例子中发现缺口。
2. 随项目补齐：IK 学最小二乘与伪逆，标定学误差与优化，策略训练学概率与梯度。
3. 从第一个实验开始保存配置、结果和失败；每完成一个阶段，检查结论是否由证据支持。

当前可先做 MATH-01 一个坐标例子，给手头任务填写 EXP-03 配置和 EXP-05 恢复卡；导数、统计与求解随 IK/控制/标定进入。所有内容仍计入原阶段计划，不要求先刷完36题。

## 理论、代码与可验收成果

| 类型 | 当前要求 |
|---|---|
| 理论学习 | 一次只回答一个数学或实验问题，例如“为什么雅可比接近奇异时求解会放大误差”。 |
| 代码实践 | 用短程序验证矩阵、有限差分、最小二乘或统计量；不先建立庞大的数学代码库。 |
| 小项目/验收 | 一份可复跑的实验记录：问题、假设、数据、配置、对照、指标、结果、局限和下一步。 |

无真机替代：全部可在普通电脑上进行；实验数据可来自合成、仿真或公开数据。

成果尽量复用到总路线的项目版本中；运行成功、指标验证和硬件验证分别记录。

## 弹性推进与学习记录

- 每周可用 10—12 小时，先承诺约 8 小时核心任务，其余用于调试、实验室插单和补缺口。
- 同时推进一个主成果和一个轻量支线；忙碌周保留一次复跑或记录整理，恢复时重新估计范围。
- 实验室任务与个人学习分别记录；满足同一验收条件的工作可抵扣，避免重复学习。
- 中断记录至少包含：当前目标、文件/提交版本、运行命令、已有结果、卡点、下一步。
- 论文记录至少包含：问题、输入输出、关键方法、实验设置、结论边界、一个可验证的问题。
- 每四周复盘一次。通过小练习确认已掌握的内容可以跳过；“读过”与“实现并验证过”分别标记。
- 作品集采用可公开代码与数据，写明个人贡献，并区分离线、仿真与真机证据。
