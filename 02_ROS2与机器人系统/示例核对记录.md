## 已通过的检查

| 范围 | 实际执行内容 |
|---|---|
| JointState | 按名字取值；缺关节、重复名字、长度错误、NaN、可选空数组检查 |
| 小发布者 | 讲义中的 StateSource 定时发布，同一进程内另一个节点成功订阅合成值 |
| 参数与定时器 | 启动参数覆盖、只读拒绝运行时 set、仅改参数值不会自动改变已创建 timer 的周期 |
| 时钟 | steady timer 片段构造；use_sim_time 启用但未接到 /clock 时为未初始化时间 |
| QoS | 不兼容/兼容配置检查；修正返回元组的用法，并核对 SYSTEM_DEFAULT 可能产生 WARNING |
| 模型 | check_urdf 解析；从 XML 关节链计算三组 FK；Xacro 改长度、展开并再次解析 |
| TF2 | 数值矩阵与逆；实际 Buffer 插入关系并查询方向、指定时刻、latest 与未来时刻失败 |
| 时间算法 | 整数 ns、近邻配对、超阈值拒绝与接收活性检查 |
| 离线 bag | 四条 JointState 序列化写入临时 sqlite3 bag，读回字段一致，bag info 正确显示 4 条 |
| 包与 launch | 临时 ament_python 包 colcon 构建、入口发现、launch 安装与两个 Node action 的描述构造 |
| 轨迹消息 | 两点轨迹构造；名字、长度、有限值、时间顺序的有效/无效样例 |
| 传感消息 | RGB8 行填充解码、错误长度/step/encoding；字节流半帧、噪声、符号位与校验拒绝 |
| 输入检查 | inactive、无状态、超时、NaN、越界拒绝及正常输入 |
| 教材结构 | 10 节讲义与 10 份答案，每节四题；Python/shell 片段语法与本地导航检查 |

临时包中的 recorder 只用占位入口检查安装规则；它不是已实现的订阅记录器。完整的记录节点和整套学习项目由你组织。

launch 对象构造会初始化日志路径，本次检查显式使用了可写临时日志目录。该设置属于工具验证环境；自己的终端按实际路径和权限检查。

## 尚未完成的运行验证

本次沙箱限制 UDP，探测产生了中间件网络警告。同进程内消息收发通过，不能据此宣布跨进程发现和通信已通过。

以下仍需要在你的学习终端按讲义验证：

- 两个独立节点进程通过 launch 协同运行；

- robot_state_publisher 的网络消息链与 RViz 显示；
- RRBot 模拟硬件、控制器切换与动作反馈；
