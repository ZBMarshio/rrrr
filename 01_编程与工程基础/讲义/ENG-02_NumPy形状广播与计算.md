## 先把“形状”当作数据说明

建议每次计算前写四件事：

```text
q_obs: (N, 2), 行=时间，列=关节，单位=rad
q_ref: (N, 2), 同一时间与关节顺序，单位=rad
error = q_obs - q_ref: (N, 2), 单位=rad
mean(error**2, axis=0): (2,), 单位=rad²
sqrt(...): (2,), 单位=rad
```

`axis=0` 在这个例子中表示把第 0 维的各时刻聚合掉，保留每个关节；不是说“挑选第 0 行”。`axis=1` 则会把关节维聚合掉。

NumPy 能检查一部分形状兼容性，却不知道两列究竟是左臂关节还是图像宽高。形状相同，还需要检查物理含义、时间对齐和单位。

## 常见细节

- `(N,)`、`(N, 1)`、`(1, N)` 是不同形状。`q[:, 0]` 通常去掉列维，`q[:, 0:1]` 保留它。
- 广播从末尾维度对齐，长度相等或其中一个为 1 才兼容。`(N, 2) + (2,)` 可给每个关节加各自偏置；没有必要先复制成 N 行。
- `*` 是逐元素乘法，`@` 是矩阵乘法。`q.T` 改变排列，`reshape` 按元素顺序重新解释形状；不能靠 reshape 把时间轴变成关节轴。
- 基本切片常得到共享数据的视图。保存“原始数据”时，想清楚是否需要 `copy()`。高级索引的复制行为另看文档，不以“看起来像取子集”判断。
- 原始计数/索引可以是整数，角度计算先明确浮点类型。给整数数组原地写入小数可能丢掉小数。
- `np.nan` 和无穷值可能一路传播到统计结果。先决定拒绝还是有依据地过滤，并记录过滤规则。
- `np.allclose` 的容差跟量纲和任务有关。不要只因默认容差通过，就认为真实机械臂精度达标。

## 练习

<a id="ex1"></a>

### 第 1 题：不用运行，先写形状。约 20 分钟

```python
import numpy as np
q = np.array([[0., 1.], [0.1, 0.9], [0.2, 0.8], [0.3, 0.7]])
bias = np.array([0.1, -0.2])
```

写出以下表达式的形状，若不合法说明原因：

1. `q[:, 0]` 和 `q[:, 0:1]`
2. `q + bias` 和 `q + bias[:, None]`
3. `q * q` 和 `q @ q.T`
4. `np.mean(q, axis=0)` 和 `np.mean(q, axis=1)`

为每个合法表达式写一句数据含义；对于 `q @ q.T`，注意它已经不再是逐点位置误差。

<a id="ex2"></a>

### 第 2 题：算出两根关节各自的 RMSE。约 30—45 分钟

从学习指南样例构造两个 `(4, 2)` 浮点数组，自己实现 `rmse_per_joint(q_ref, q_obs)`：

- 输入必须是相同形状的非空 `(N, 2)` 有限数值数组。
- 不修改输入，输出 `(2,)`。
- 对形状错误、空输入和 NaN 抛 `ValueError`。

先手算每列的四个误差与平方，再写 NumPy。之后只把第一关节观测全部加 0.1 rad，预测哪项指标会改变，再运行确认。改动后的具体数值也可以手算。

<a id="ex3"></a>

### 第 3 题：我只改了“局部”，原始数据怎么也变了？约 15 分钟

在独立运行中重新创建第 1 题的 q，再预测：

```python
part = q[:2]
saved = q[:2].copy()
part[0, 0] = 99.0
saved[0, 0] = -1.0
print(q[0, 0], part[0, 0], saved[0, 0])
```

解释怎样保留一份独立的基准数据。再想想：`saved = q` 能做到吗？

<a id="ex4"></a>

### 第 4 题：不均匀时间，让隐藏的广播错误暴露出来。后续约 30 分钟

```python
t = np.array([0.0, 0.1, 0.3])
q = np.array([[0.0, 1.0], [0.1, 0.8], [0.5, 0.4]])
v_bad = np.diff(q, axis=0) / np.diff(t)
```

这段代码不会报形状错误。先手算两个时间区间各关节的速度，再说明 v_bad 为什么算错。实现 `interval_velocity(t, q)`，要求时间一维、长度一致、至少两行、数值有限且时间严格递增。

增加重复时间与倒序时间样例，确认计算前被拒绝。输出表示区间平均变化率，选择区间中点或端点作为绘图位置时写清约定。

## 最低验收

W01 先通过第 1、2 题，并能解释每个 axis 的含义。第 3 题用于保护原始数据，第 4 题在接触速度和轨迹时补齐。遇到报错先写形状，遇到没报错也要检查含义。

## 直觉与回顾

可以把 shape 理解为一张有行列标题的表格。NumPy 只看到格子大小，你要负责标题。两张表都为 12 列，不代表能直接相减；关节顺序不同、一个用角度一个用弧度，都会让形式正确的计算失去意义。

广播很像按明确规则把一张小表对齐到大表上。第 4 题的价值在于让你亲眼看见：程序接受你的写法，只能证明规则允许，并没有替你确认意图。

写下你这次真正确认的一件事：“我知道 axis=0 了”太宽；“我用四行两列手算，确认输出只剩两列”更具体。
