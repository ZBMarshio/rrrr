## Default Argument Values
- 实参至少覆盖没有默认值的形参，最多不超过形参总数，多了少了都会 TypeError
- The default values are evaluated at the point of function definition in the defining scope
函数定义时记录默认参数的值，并在之后的运算中持续引用这个值，不会受到外界变量更新的影响

### 示例
'''
def ask_ok(prompt, retries=4, reminder='Please try again!'):
    while True:
        reply = input(prompt)
        if reply in {'y', 'ye', 'yes'}:
            return True
        if reply in {'n', 'no', 'nop', 'nope'}:
            return False
        retries = retries - 1
        if retries < 0:
            raise ValueError('invalid user response')
        print(reminder)
'''

### 默认列表引用问题
- 解决方法：
'''
def f(a, L=None):
    if L is None:
        L = []
    L.append(a)
    return L
'''

- 如果在定义中使用L=None，不传入实参时每次使用函数都会重新内部创建一个新的列表

## More on Modules
- 一个模块*首次*作为模块被引入或者作为脚本使用的时候，模块内部的*顶层*执行语句（比如在class/def外的print()）会被执行一次，反之不在顶层的语句则不会执行
- 每个模块都有自己的一个全局命名空间，可以使用modname.itemname调用或者修改模块内部的参数值

- Modules can import other modules.

- import fibo

- from fibo import *
*不推荐使用*，引入模块内所有函数，除了使用“_“开头的函数
- import fibo as fib
效果同一，但可以自己定义模块名称
- from fibo import fib as fibonacci
类似上一条，可以定义模块内的函数名称

## Instance Objects 实例对象
 The only operations understood by instance objects are attribute references.There are two kinds of valid attribute names: data attributes and methods.

### data attributes
- 实例的数据属性不需要额外声明，赋值之后就存在了

### methods
- A method is a function that “belongs to” an object.
- 承用上面的例子
'''
class MyClass:
    """A simple example class"""
    i = 12345
    def f(self):
        return 'hello world'
x = MyClass()
'''
- x.f是一个有效的方法引用，而x.i是属性引用
- x.f是*方法对象*，MyClass.f是函数对象，这两者不是同一个对象
-  By definition, all attributes of a class that are function objects define corresponding methods of its instances. 
也就是使用x.f的时候，会自动传入self(也就是x)到这个方法中，
即x.f()==MyClass.f(x)

## Method Objects 方法对象
- 虽然使用x.f()会立即调用这个方法，但一般可以使用xf=x.f暂存
- The instance object is passed as the first argument of the function.也就是x.f()==MyClass.f(x)

### 方法对象的具体调用
- 调用方法对象的时候，会先在实例中寻找，找不到的时候再去类中寻找
- 找到类中的函数后，会把*实例对象的引用*和*函数对象的引用*打包成方法对象
- 调用方法的时候传入参数列表后，py会把实例自身和参数列表合并然后传入方法对象，也就是x.f(10)==MyClass.f(x, 10)

##  Class and Instance Variables 类/实例变量
- 实例变量被某个实例特有，而类变量（包括变量和函数）被所有这个类的实例所共享，引用实例修改实例变量的时候不会影响其他实例
- 上面一点在*可变对象（mutable objects）*中比较特殊，如果不在__init__中创建可变对象，则这个可变对象为类共有，修改是会在原地修改；作为对比，如果是不可变类变量，会根据这个实例创建一个新的属性

## Inheritance 继承
'''
class DerivedClassName(BaseClassName):
    <statement-1>
    .
    <statement-N>
'''
- 派生类继承的时候寻找BaseClass也符合LEGB的寻找要求
- 定义派生类的时候，括号里的BaseClassName也可以是表达式或者语句，只要最后得到的结果还是一个类即可
- 派生类会继承基类的属性，派生类找不到的属性会在基类中继续寻找，方法的引用也类似

- 两个简单的方法：isinstance()和issubclass()

## Exceptions
Errors detected during execution are called *exceptions* and are not unconditionally fatal.
- 报错信息：一般为
'''
>>>10 * (1/0)

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ZeroDivisionError: division by zero
'''
由两部分组成：

### 错误位置：Traceback 栈回溯
- 有固定开头：“Traceback (most recent call last):“提醒应该从下网上报名看，最下面是错误类型和使用错误的位置，从下往上会有引用嵌套，根据提示位置可以一直向上追溯
- 还需要注意，当使用标准输入（standard input）的时候，不会打印错误源码，作为对比，以下是从文件中运行代码的报错，会直接写出源码
'''
Traceback (most recent call last):
  File "/home/m/桌面/rrrr/01_编程与工程基础/test.py", line 1, in <module>
    10 * (1/0)
          ~^~
ZeroDivisionError: division by zero
'''

### 错误类型
- 报错有很多类型，可以在运行错误信息中找到，内置类型错误都有标准错误名，但这些错误名不是保留关键字，也可以自己进行定义

## Handling Exceptions
'''
while True:
    try:
        x = int(input("Please enter a number: "))
        break
    except ValueError:
        print("Oops!  That was no valid number.  Try again...")
'''
- 通常使用try ... except语句进行特定的错误类型捕获，这种情况下只会关注特定类型的报错，比如上例，能转成int就break结束；转不了抛ValueError，但被下面的except捕获、打印提示、继续while，不会抛到外层
- 或者使用Ctrl+C来中断程序，用这种方法实际上是向程序发出一个信号，抛出了KeyboardInterrupt的错误
- try中的函数如果有错误也会被except捕获

### try ... except
- 正常情况下会首先执行try中的语句：无报错就会跳过except语句，产生报错的时候会先与except的错误先进行匹配；符合错误类型就会执行except下的语句，不符合错误类型的时候会先向上一层try寻找，没有的时候会终止程序并打印traceback
- 一个try下可以有多个except，但每次只会有一个except执行；如果except语句中还有错误，也不会被同级的except中捕获，此时同样要有上一级try才能被检查到；一个except语句也可以跟多个错误类型，但是要用*元组(tuple)*表达（例如except (RuntimeError, TypeError, NameError):）
- 一个例子
'''
class B(Exception):
    pass
class C(B):
    pass
class D(C):
    pass
for cls in [B, C, D]:
    try:
        raise cls()
    except D:
        print("D")
    except C:
        print("C")
    except B:
        print("B")
'''
- 上面的例子中，B是Exception的派生类，C是B的派生类，D是C的派生类，在try中依次raise出BCD，会依次输出BCD。
关键在于两点：1.语句按顺序执行；2.except只会匹配本类和其派生类的错误。

### exception’s arguments
- 
'''try:
    raise Exception('spam', 'eggs')
except Exception as inst:
    print(type(inst))    # the exception type
    print(inst.args)     # arguments stored in .args
    print(inst)          # __str__ allows args to be printed directly, but may be overridden in exception subclasses
'''
错误类型也可以携带一些信息，使用“except Exception as inst”把错误类型实例的信息给到inst，inst.args是参数元组,print(inst)打印的是 str(inst)

### BaseException
- BaseException是所有错误类型的基类，一般情况下派生类中的Exception类会被捕获处理，其余通常与结束程序有关，不会被处理
- Exception类几乎包含了所有错误类型，实践中尽量只处理可以预见的打算处理的错误类型，其余错误可以最后重新抛出用于向上传播，以便于调试处理

### else clause
'''
for arg in sys.argv[1:]:
    try:
        f = open(arg, 'r')
    except OSError:
        print('cannot open', arg)
    else:
        print(arg, 'has', len(f.readlines()), 'lines')
        f.close()
'''
- else作为try ... except的附加可选语句，只有在try执行不报错后才会被执行
- 用else可以分开需要保护的代码和后续代码，缩小try语句下的范围

## Raising Exceptions
'''
try:
    raise NameError('HiThere')
except NameError:
    print('An exception flew by!')
    raise
'''
- 使用raise可以主动抛出错误，可以抛出错误类型并修改字符串参数（如raise NameError('HiThere')），也可以直接抛出一个错误类型（如raise NameError），此时会自己实例化
- re-raise:使用raise可以重新抛出当前正在处理的错误，用于只记录错误但不处理的情形，可以让错误继续向上传播

## Exception Chaining
在except语句中raise一个错误会产生*自动错误链*，报错的时候会将一连串错误一起显示
- 在except语句下使用*raise...from...*语句可以显式说明错误的来源
- 特别地，使用*raise...from None*可以隐藏自动错误链
