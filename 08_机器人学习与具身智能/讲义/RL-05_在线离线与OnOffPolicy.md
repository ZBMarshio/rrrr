## 导读

**为什么学这一节。** 在线/离线与on/off-policy关注不同关系。把这些词拆开，才能看清算法需要怎样的数据，以及当前数据是否合适。

## 用两个问题代替一组容易混的词

第一个问题：训练期间还能否获取新的环境交互？online允许继续采集；offline RL通常给定一个固定数据集，训练时不再用新环境经验更新。离线训练完成后可以去独立评测，但若拿评测交互继续更新，就改变了实验约定。

第二个问题：用来更新的经验由哪个行为策略产生，和当前学习目标策略是什么关系？on-policy强调当前/近期采样策略与更新目标的匹配；off-policy允许在相应算法条件下利用不同策略产生的经验。

两组词关注不同维度。在线采样的SAC可以off-policy；一轮PPO用近期rollout更新几轮，仍常归为on-policy。并不是“梯度更新时没连机器人”就叫offline RL。

| 工作流 | 是否新增训练交互 | 数据复用关系 |
|---|---|---|
| PPO边采边更新 | 有 | 近期策略rollout，有限轮使用 |
| SAC边采边从buffer更新 | 有 | 常见off-policy流程，可用历史经验 |
| 固定数据上的离线RL | 无 | 方法要处理数据覆盖和策略偏移 |
| 固定示教上的BC | 无 | 监督模仿；通常不硬套RL的on/off-policy分类 |

## 为什么off-policy不自动等于适合离线RL

允许复用经验，不代表能够可靠评价任意未见动作。若数据只包含a0，Q对a1的估计缺少约束；max目标或actor可能偏向被高估的a1。在线时或许还能收集新经验纠正，固定数据时这条纠错路更受限。

“buffer很大”也不等于覆盖足够；要看状态、动作、任务与行为策略的实际分布。离线方法可能用约束、保守估计或不同目标减轻问题，具体算法之后按需要学。

## 最小实践

画一条工作流，标出数据采集器、行为策略版本、buffer、更新目标策略、评测入口；再给它分别标在线/离线及on/off-policy。分类服务于资源和证据判断，不必先背所有算法名。

使用固定示教时先判断你能得到什么学习信号：有动作标签可以做BC；要做价值学习，还需奖励/任务定义、转移与边界等信息，或明确这些信息如何可靠重建。

## 练习

<a id="ex1"></a>

### 第1题：分别分类。约20分钟

为表中四种工作流写两句判断依据。有人说“用了经验回放，所以不需要再接环境”，错在把哪两个条件混在一起？

<a id="ex2"></a>

### 第2题：未知动作。约20分钟

固定数据只记录某状态采取a0并获得奖励1后终止，没有a1。Q(a0)=1、Q(a1)=5时，贪心策略选哪个？数据能否证实a1更好？若在线与离线，分别还能怎样获得证据？

<a id="ex3"></a>

### 第3题：数据够做什么。约25分钟

手头只有(观测,教师动作)，没有下一观测、奖励或结束信息。先写能做的最低学习任务，再写若转成离线RL需要补充/重建什么。不能凭空给“成功数据”每步都贴同一种回报后声称问题已解决。

<a id="ex4"></a>

### 第4题：为项目画数据来源图。约30分钟

选现有BC或计划PPO流程，标注每份数据的产生者、产生时刻、是否用于更新、是否独立评测；估算新增交互成本。没有实验时写设计图即可，状态仍为待验证。

## 直觉与复盘

online/offline像“能不能再去现场取样”，on/off-policy像“这份经验是谁按什么规则采的”。先看证据从哪里来，分类才会对实际决策有帮助。

复盘：你说一个方法能用已有数据时，指的是能读取文件，还是它的学习目标也得到足够支持？
