# 新技术评估卡

[维护约定](../内容维护约定.md) · [LEARN-08导读](../导读.md#learn-08) · [知识索引](../知识索引.md#learn-08)

模板建立：2026-11-07。用于判断是否值得进入一个独立小实验，不因填写此卡就改动当前主线。

```text
记录日期 / 方法或项目名 / 原始论文与官方代码：
我当前已有的一个失败或瓶颈：
它声称解决的问题 / 证据来自什么任务：
学习信号：示教、奖励、自监督、其他或组合：
系统作用：动作、价值、转移、表征、子目标、规划：
表示/训练机制 / 关联现有知识编号：
最低前置 / 已有证据 / 尚缺：
数据、动作、本体、环境接口是否匹配：
算力、交互、调试与个人时间预算：
最简单的可比基线：
只验证的一项变化 / 固定案例 / 指标与分母：
最小试跑能否完成 / 具体证据：
失败或超预算时退回哪里：
决定：暂存资料 / 做一个独立试验 / 选题节点再考虑：
下一次复核触发：
```

先记录问题和证据，再登记热度或榜单位置。同一个旧方法能解决当前问题时，可以优先把实验做清楚。
