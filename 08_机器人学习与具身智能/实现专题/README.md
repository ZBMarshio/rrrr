## 文件怎么命名和更新

从模板复制，命名示例为“实际年月_知识编号_任务或工具.md”；年月写实际创建时间，不提前标未来日期。必要时再加v0.2等修订号，保留旧实验引用的版本。

每份先写关联基础、任务/数据契约、环境/依赖、官方资料与阅读范围，再写步骤、习题或项目、验收和已验证范围。命令未运行就标待运行；安装前先确认项目隔离环境与解释器。

基础讲义负责理解原理，实现专题负责当时的工具适配；相同推导不重复抄一遍。若只需修一条API调用，就只记录这条变更及核对结果。
