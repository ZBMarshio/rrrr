## 本章导读

**为什么学这一章。** 前面的系统基础让机器人能够接收观测、执行动作和留下反馈。这一章进一步问：怎样利用示教、奖励或预测任务，让行为和模型从经验中改进？

**学完会有什么变化。** 学习前，BC、RL、世界模型与VLA容易混成一串方法名；逐步学习后，你能区分学习信号、策略表示和系统作用，说明数据从哪里来、更新什么、怎样检验效果。

**接下来能做什么。** 可以先完成状态BC和标准环境RL两个小闭环，再选数据覆盖、时延、动作表示或模型误差中的一个问题深入。方法选择随证据与资源调整，分节导读先帮助你找到入口。

分节阅读：[18个知识主题的导读](导读.md)。具体前置、资料和掌握层次继续查知识索引。

## 学习路线

1. 先学通用契约：观测、状态、动作、episode、时间、坐标、归一化与评测；用简单 BC 建立数据到动作的最小闭环。
2. 并行建立 RL 入门：小 MDP/表格方法 → 标准环境接口 → 用现成实现训练 PPO 或 SAC 中的一种，理解奖励、终止与评测。两条入门路线各保留一个小成果。
3. 2027 年春根据兴趣、数据与算力选一个主项目：BC + ACT/扩散策略，或控制/随机基线 + 一种 RL 方法；先完成可信对照实验，再选择模型学习、迁移或 VLA 扩展。
4. 研一在稳定基线之上提出一个窄问题，例如数据质量、奖励设计、延迟鲁棒性、动作表示或未见场景泛化；根据证据调整技术路线。

## 理论、代码与可验收成果

| 类型 | 当前要求 |
|---|---|
| 理论学习 | 区分学习信号、策略表示、模型使用方式和任务能力；理解示教、交互奖励、自监督数据各自提供什么信息。 |
| 代码实践 | 自己实现简单 BC 和一个小型表格 RL 更新；深度 RL、ACT 等先阅读并使用成熟实现，完成数据/环境/评测适配。 |
| 小项目/验收 | 本科保留 BC 与 RL 两个入门小闭环，再将其中一条深化为可复现主项目；报告基线、固定评测、开销、失败和一次消融。 |

无真机替代：BC 使用匹配任务的公开/合成示教；RL 使用 Gymnasium 小任务，随后按需用机器人仿真。真机只作后续受控验证。

成果尽量复用到总路线的项目版本中；运行成功、指标验证和硬件验证分别记录。

## 方法全景：这些分支可以组合

| 观察角度 | 主要内容 | 当前定位 |
|---|---|---|
| 学习信号 | 示教、交互奖励、自监督预测、人类反馈 | BC 与 RL 基础都建立小闭环 |
| 模仿学习 | BC、数据聚合、序列策略、动作块 | 深化候选之一 |
| 强化学习 | 值方法、策略梯度、actor-critic、在线/离线、模型式/无模型 | 独立基础路线与深化候选 |
| 动力学与世界模型 | 状态转移预测、潜在状态、模型误差、不确定性、想象与规划 | 理解接口，研一按题深入 |
| 规划与学习结合 | 学习模型/代价、残差策略、技能、任务与运动规划 | 保留传统系统与学习方法的连接 |
| 策略表示 | MLP、Transformer、扩散、流匹配等 | 表示方式与学习信号是不同维度 |
| 泛化与部署 | 数据覆盖、域随机化、sim-to-real、多任务、在线适应、时延 | 从项目评测开始贯穿 |
| 基础模型与 VLA | 视觉/语言/动作对齐、动作表示、预训练与适配 | 可更新分支，按资源选择验证范围 |
| 机器人任务 | 抓放、接触、双臂、灵巧操作；移动与全身任务可后续扩展 | 先围绕现有机械臂形成成果 |

## 技术更新规则

- 每个阶段末复核一次方法候选；正在运行的基线固定版本，新增方法先在独立实验中评估。
- 新技术先登记：解决的问题、所属分支、前置知识、数据/算力/接口需求、可复现证据、最小验证。
- 经典基础与已验收能力保留；热度变化主要影响扩展方法选择。
- RL 深化重点检查样本效率、奖励与评测、交互成本和部署限制；VLA 深化重点检查数据/本体/动作兼容与泛化证据。
- 4060 Laptop 的计划预算为约 8 GB 显存；训练前实测，控制视觉分辨率、批量与模型规模。大模型完整训练/微调不作为本科必做条件。
