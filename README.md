## 个人条件与目标

- 已有 Python、Linux、ROS 2 和机器学习基础，学习从检查薄弱点开始。
- 个人学习时间约每周 10—12 小时；实验室任务单独记录，真机时间不作为进度前提。
- 个人设备为 Ubuntu 24.04 与 RTX 4060 Laptop。按官方 8 GB 显存规格做预算，实际训练前测显存和吞吐。[NVIDIA 规格](https://www.nvidia.com/en-us/geforce/laptops/40-series/)
- 本科阶段形成可解释、可复现、可展示的工程与学习项目；后续研究方向保持开放。
- 机器人学习包括 IL、RL、模型学习、规划与学习结合、迁移泛化和基础模型。VLA 是其中一个分支。
- 版本日期：2026-11-02。新增方法根据问题与证据选择，运行中的实验固定版本。

## 怎样使用导读

导读补充日期：2026-11-07。第0—8章的 README 先说明整章为什么学；进入学习小节后，开头的三段分别回答学习动机、学完的变化和下一步用途。第0—7章放在各节讲义开头，第8章集中在[各节导读](08_机器人学习与具身智能/导读.md)。

先用导读找到当前问题的意义，再做本周的一项练习。可以把自己预期的变化和实际结果写入复盘表；读过导读不直接标为已掌握，也不增加一轮必须通读的任务。

例如：[Python入口与对象](01_编程与工程基础/讲义/ENG-01_Python模块类与异常.md#intro) · [TF坐标查询](02_ROS2与机器人系统/讲义/ROS-05_TF2与坐标查询.md#intro) · [BC闭环](08_机器人学习与具身智能/导读.md#learn-02) · [RL价值与回报](08_机器人学习与具身智能/导读.md#rl-01)。

## 从哪里开始

1. 当前先打开[第一阶段周计划](阶段计划/第一阶段_学习范围与周计划.md)，了解本期范围并从 W01 开始；需要整体关系时查[总知识网络](总知识网络.md)。
2. 进入当前方向的 `README.md`，了解内容、深度、路线与资料。
3. 临时遇到问题时打开该方向的 `知识索引.md`；知识编号会链接到最低前置与资料入口。
4. 每次只选一个最小可验收成果；理论与代码配对，保留自己的解释和验证结果。

## 维护方式

- 先解释、实现、验证，再扩大规模；导师协作以提示、代码审查和实验设计为主。
- 每四周复盘当前成果、缺口和时间条件；忙碌时收缩扩展项，保留可恢复记录。
- 已有能力通过小练习抵扣；实验室任务满足同一验收条件时也可抵扣。
- 学习记录可放入对应目录；实际项目代码沿用已有合适工程，避免为每个知识点重复搭环境。
- 资料以官方文档、作者课程和原始论文为主。目录中的链接是资料入口，实际安装和复现前再检查版本、数据与依赖。
