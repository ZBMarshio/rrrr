## 1. 参考接口与物理跟踪

![位置参考、回显规则与物理状态](/home/m/桌面/rrrr/06_仿真与系统集成/图示/参考接口与物理跟踪.png)

对应 [SIM-05 第 2 题](../讲义/SIM-05_mock可视化与物理证据.md#ex2)，模型为[单关节转子](../模型/单关节转子.xml)。

初态 q=qd=0，参考 0.5 rad；PD=(8,0,0.8)，每 0.005 s 更新，物理 h=0.001 s，力矩限制 ±2 N·m，观察 2 s，无延迟。D 使用测得速度负反馈，阶跃参考速度取零。

橙色位置线同时表示参考与理想位置回显规则，初始物理状态单独标记；没有运行 ROS mock。蓝色实际 q 来自 motor 与动力学，右侧分别记录 raw 和实际广义执行器力矩。两类后端解释不同输入，不用于同接口性能排名。

## 2. 落体、接触与物理步长

![球落地的高度、力与压入](/home/m/桌面/rrrr/06_仿真与系统集成/图示/落体接触与步长.png)

对应 [SIM-03 第 3、4 题](../讲义/SIM-03_时间渲染与接触.md#ex3)，模型为[球落地](../模型/球落地.xml)。

球半径 0.05 m、质量 1 kg，初始球心 z=0.3 m、速度零，重力 9.81 m/s²。接触参数、求解器保持 XML 中设置，分别运行 h=0.001/0.002/0.005 s，观察 1 s；日志前 forward 同步当前派生量。

飞行段与独立自由落体式对照。法向力来自本例唯一地面/球接触；尾部平均接近 9.81 N。负接触距离对应本图所示软模型压入，最大约 11—16 mm，不能作为真实材料或手爪的变形/力精度。

不同步长下峰值与压入不必呈现“某数越小越好”；需要数值收敛和真实参数基准分别判断。图中没有仿真抓取。

## 3. 双关节几何与执行

![两关节 IK、轨迹与动力学执行](/home/m/桌面/rrrr/06_仿真与系统集成/图示/双关节几何与执行.png)

对应 [SIM-01 第 3 题](../讲义/SIM-01_模型加载循环与状态.md#ex3)及 P1 接口练习；模型为[平面双关节](../模型/平面双关节.xml)。

初态 q=[-0.6,1.1] rad，目标 TCP=[0.3,0.2] m。复用第三章带限位位置 IK；再用第四章 2 s 三次关节轨迹、每关节 PD=(8,0,0.8)、±2 N·m 限幅，物理步长 0.001 s，控制周期 0.005 s，总观察 3 s。

右图分开保存 q_ref 与实际 q。左侧参考 TCP 来自 FK(q_ref)，实际 TCP 来自 MuJoCo tool0 site；每次同时核对 FK(q_actual)。初末连杆为几何示意，不是渲染画面。

模型启用指定耦合动力学，但关闭几何碰撞；这条无障碍链没有经过 MoveIt、在线 ROS、真实视觉或真机。终点数值误差不代表真实定位精度。

## 4. 模型参数、命令延迟与评测

![固定 PD 的参数和延迟敏感性](/home/m/桌面/rrrr/06_仿真与系统集成/图示/参数时延与评测.png)

对应 [SIM-09 第 2 题](../讲义/SIM-09_域随机化与迁移.md#ex2)。复用第一图的零初态、参考、控制器、步长和 2 s 窗口。

纵轴将转子质量与整个惯量张量同时乘 0.5/1/2，阻尼保持 0.1；横轴命令延迟为 0/10/20 个控制 tick，即 0/50/100 ms。用 FIFO 延迟控制作用，初始队列为零；每格从基线 XML 重建模型并重置控制器。

左图 RMSE 包含初始误差。右图颜色/文字表示尾窗 [1.8,2.0] s 内始终同时满足位置误差 ≤0.02 rad、速度绝对值 ≤0.05 rad/s；格内数字是该窗最大速度绝对值。

这是固定控制器的九种模型/时延敏感性结果，未随机化训练策略，也没有真实设备误差范围。它帮助找出值得继续测量的条件，不能直接宣布 sim-to-real 成功。

## 怎样使用参考图

先自己写预测、运行一个小例子，再打开对应图。保留实际参数与原始日志，能解释一个反例后再增加接口。图示不代填个人学习进度。
