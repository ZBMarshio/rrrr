# SIM-05：先知道这次成功验证了什么

## 导读

**为什么学这一节。** 界面中的机器人移动，可能来自参考轨迹、状态回放或动力学反馈。理解来源能让一次成功真正对应一个被验证的问题。

**学完会有什么变化。** 从笼统地说仿真跑通，进到能区分接口回显、可视化和物理状态，给每种结果写清支持范围。

**接下来能做什么。** 可以选择合适后端验证接口或跟踪，按[LEARN-07](../../08_机器人学习与具身智能/导读.md#learn-07)准确报告离线、模拟与实际任务证据。

## 资料与范围

对照 [Jazzy mock components](https://control.ros.org/jazzy/doc/ros2_control/hardware_interface/doc/mock_components_userdoc.html)与 [ROS-08](../../02_ROS2与机器人系统/讲义/ROS-08_ros2_control与执行接口.md)。mock 的具体行为由插件与配置决定，不能只看“仿真”二字。

## 几种常见证据

| 观察 | 能支持的结论 |
|---|---|
| RViz 按给定关节角显示 | 模型/TF/显示链相应部分可工作 |
| mock 命令映回状态 | 命令、控制器与反馈管线在该模拟规则下工作 |
| 规划器返回路径 | 当前模型/场景/限制下找到了候选结果 |
| MuJoCo 经执行器推进状态 | 相应动力学/数值模型下的状态演化与跟踪 |
| 真实设备测量 | 相应实际条件下的行为，还需记录测量与任务结果 |

有的 mock 可对速度/加速度做简化积分；这仍不等于实测惯性、摩擦和接触。可视化可以展示真实反馈，也可以展示规划/回放参考，必须指出来源。

## 用同一个位置目标看差异

理想位置回显可把目标直接返回为状态；物理后端需要伺服/执行器逐步接近。两者可以服务于不同的测试。

## 练习

<a id="ex1"></a>

### 第 1 题：给现有成果贴对说明。约 15 分钟

取前几章三个已有结果，分别写输入来源、反馈来源、运行层次、能证明的结论和未验证项。复用原记录，不新增一套报告。

<a id="ex2"></a>

### 第 2 题：理想回显和实际跟踪。约 25 分钟

位置目标 0.5 rad，先用一个明确的理想回显，再用单转子+PD 跟踪。解释两条状态曲线为何不同，以及它们实际分别接收哪种控制量。

<a id="ex3"></a>

### 第 3 题：不能成立的结论。约 15 分钟

“RViz 夹爪合上并附着了物体，所以实机已验证抓取。”“mock 的关节误差为零，所以惯量选得正确。”分别缺少什么证据？

<a id="ex4"></a>

### 第 4 题：项目展示怎样讲清楚。约 20 分钟

为 P1/P2 写三句话：已运行哪条链、实测了哪些指标、下一项需要什么独立验证。把成功视频与参数/日志对应起来。

## 直觉与回顾

不同测试像检查同一设备的不同部分。线路接通、路线能规划、机构能运动，各自都是成果；清楚边界会让下一步更具体。

复盘把一个笼统的“跑通了”改成一条别人可以复核的陈述。
