## 本章导读

**为什么学这一章。** 想让机械臂到某个位置，先要知道关节数值与空间运动有什么关系。机器人学把画面中的姿态变成可以计算、求解和独立核对的量。

**学完会有什么变化。** 学习前，关节角、末端位置和坐标变换可能混成一组数字；学习后，你能说明各自所属空间，预测一个关节变化的影响，也能区分求解失败、不可达与接近奇异。

**接下来能做什么。** 可以实现平面机械臂的FK、雅可比和IK，为轨迹与控制提供几何基础。三维表示、动力学和旋量随后按任务补，不必一次掌握所有推导。

## 学习内容与掌握层次

| 层次 | 内容 |
|---|---|
| 必须掌握 | 旋转矩阵、齐次变换、四元数的使用；关节/任务空间；FK；简单解析 IK 与数值 IK；雅可比、奇异性和限位；惯性、重力、摩擦和力矩的含义。 |
| 了解即可 | 旋量、指数积、动力学方程各项、冗余与零空间、静力学映射。 |
| 以后深入 | 刚体动力学推导、闭链、多接触、系统辨识和复杂约束。 |

## 学习路线

各节资料选读、易错细节、练习与直觉解释见[九节讲义导航](学习指南.md)。先完成当前周的几何或数值成果，再按需要进入动力学与旋量选读。

1. 从二维与三维坐标变换入手，明确每个矩阵把哪个坐标系中的量变到哪里。
2. 在二维机械臂上推导 FK/雅可比/IK，使用有限差分和解析解交叉验证。
3. 迁移到现成多关节模型，理解奇异、限位和动力学因素；按控制任务补理论。

## 理论、代码与可验收成果

| 类型 | 当前要求 |
|---|---|
| 理论学习 | 理解表示方式、变换复合、位置与速度关系，以及运动学和动力学的边界。 |
| 代码实践 | 自己实现一个简化机械臂的 FK、雅可比和数值 IK，再与成熟库对照。 |
| 小项目/验收 | 一个可重跑的运动学验证笔记或程序，包含可达、不可达和奇异附近的案例。 |

无真机替代：NumPy 即可完成基础验证；三维模型与运动可使用 RViz/MuJoCo。

成果尽量复用到总路线的项目版本中；运行成功、指标验证和硬件验证分别记录。
