## 第 1 题

| 点，单位 m | 理想位置可达性 |
|---|---|
| (0,0) | 不可达，两段长度不同，折叠后仍相差 0.1 m |
| (0.1,0) | 内边界可达 |
| (0.3,0.2) | 半径约 0.360555 m，在内部 |
| (0.5,0) | 外边界可达 |
| (0.7,0) | 超出 0.5 m，不可达 |

这里假设两个关节能完整转动、无障碍，任务只约束位置。边界数值计算可设合理浮点容差，不把舍入误差误判成机构能力变化。

## 第 2 题

余弦关系：

```text
cos(q2) = (x²+y²-L1²-L2²)/(2 L1 L2) = 0
q2 = ±π/2（以及对应周期表示）
```

±1.570796 不在 [-1,1]，所以本例虽在理想圆环内，在该 q2 限位下不可达。完整检查还要有 q1 限位，当前 q2 已足以排除。

## 第 3 题

直接差约 -6.263185 rad，最短周期差为 +0.02 rad：

```python
import math

def shortest_angle_delta(qa, qb):
    return math.atan2(math.sin(qb - qa), math.cos(qb - qa))
```

连续关节可按任务选择绕行与转数；带止挡关节从 +π 端跨到 -π 端没有自动存在的物理通路。这个函数只算周期表示的最短差，不是限位轨迹规划器。
