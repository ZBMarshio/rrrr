## 导读

**为什么学这一节。** 末端想往一个方向微调，应该怎样分配关节变化？雅可比把每个关节的局部影响放在同一张可计算的关系中。

**学完会有什么变化。** 从只看到一组导数公式，进到能解释每一列的方向、单位与当前构型，并用有限差分核对。

## 从“只动一个关节”开始

```text
x = f(q)
delta_x ≈ J_xy(q) @ delta_q
xdot = J_xy(q) @ qdot

J_xy = [ ∂x/∂q1  ∂x/∂q2 ]
       [ ∂y/∂q1  ∂y/∂q2 ]
```

第 1 列表示 q1 增加很小一项时，末端沿什么方向变化；第 2 列对应 q2。两个关节同时动，就是这些一阶贡献叠加。

对于本章 2R：

```text
J_xy =
[ -L1 sin(q1)-L2 sin(q1+q2)   -L2 sin(q1+q2) ]
[  L1 cos(q1)+L2 cos(q1+q2)    L2 cos(q1+q2) ]
```

这是基座 xy 位置对 rad 关节量的导数。位置增量近似只在局部有效，速度关系则针对当前构型的瞬时导数。

## 怎样验证，才不是照着自己写的公式证明自己

中心差分逐个关节扰动：

```text
J[:, i] ≈ (f(q+h e_i) - f(q-h e_i))/(2h)
```

f 来自已验证的 FK。检查两个列向量、单位和误差，不只观察函数“没有报错”。h 过大有截断误差，过小会受浮点舍入影响。

## 易错细节

- 求导时 q2 会影响第二段方向 q1+q2，q1 同时影响两段。
- 名称/列顺序与 q、qdot 保持一致；二维形状相同并不能识别关节交换。
- 速度在哪个坐标系表达，J 就要对应同一坐标系。
- m/rad × rad/s 得 m/s；把度当 rad 会使数值比例不对。
- 不能用一个姿态的 J 代替整段大幅运动，也不能把 delta_q 很大时的一阶近似当作精确 FK。
- Modern Robotics 的空间雅可比对应 twist，不能只把其下三行当作末端位置导数，详见 KIN-09。

## 练习

<a id="ex1"></a>

### 第 1 题：推导并解释每一列。约 30 分钟

从自己的 FK 求导，算 q=(0,0) 和 (0,π/2) 的 J。第二个姿态下 qdot=(0.1,-0.2) rad/s，末端速度是多少？

画各列箭头，解释为什么伸直时两列朝向相同。

<a id="ex2"></a>

### 第 2 题：用有限差分检查。约 30 分钟

实现 jacobian_xy 和一个中心差分工具，对 q=(0.4,-0.6) 及固定种子的若干构型比较。尝试 h=1e-2、1e-4、1e-6、1e-8 rad。

记录最大绝对误差；h 不是越小越好，不把某次误差趋势当成所有机器上的严格单调规律。

<a id="ex3"></a>

### 第 3 题：局部近似离精确 FK 多远？约 20 分钟

取 q=(0.4,-0.6)、delta_q=(0.01,-0.02)，比较真实位置变化与 J@delta_q。把 delta_q 减半后再比较。

观察误差怎样变化，区分“误差大小”和“位置变化本身大小”。

<a id="ex4"></a>

### 第 4 题：列交换了，形状仍然正确。约 20 分钟

人为将 J 两列交换，或将 qdot 的关节顺序交换。用有限差分/已知小步构造反例。

写出会让错误碰巧隐藏的输入，例如两个关节速度相同；换一组能暴露错误的输入。

## 直觉与回顾

雅可比可以看成当前姿态下的小地图：每一列是一只关节能把末端推向的方向与效率。姿态变了，小地图也变。

一阶近似并没有承诺“一步走到很远仍准确”。复盘选一列，先用手指比出它的方向，再用扰动结果确认。
