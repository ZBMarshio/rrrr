## 导读

**为什么学这一节。** 机械臂接近伸直时，小末端需求可能对应很大关节变化。奇异性帮助你解释这种现象，也让你知道冗余究竟提供了什么自由。

**学完会有什么变化。** 从把不稳定都归为求解器不好，进到能检查局部方向、奇异值和零空间，区分离散多解与连续冗余。

**接下来能做什么。** 可以解释阻尼IK的取舍，判断目标或轨迹为何困难，并为后续约束规划和冗余姿态选择提出检查。

## 2R 伸直时发生了什么

```text
det(J_xy) = L1 L2 sin(q2)
q2 = 0 或 π（以及周期等价）时奇异
q=(0,0) 时 J = [[0,0],[0.5,0.2]]
```

两列在同一直线上，一阶速度只能沿 y。末端可以通过有限弯曲改变 x，但这种变化不在该点的一阶线性映射中。

奇异不是“机械臂完全不能动”，而是任务相关的一些瞬时方向丢失。接近奇异时，为产生某个小末端速度，伪逆可能要求很大的关节速度。

## 用奇异值看方向强弱

J=U diag(s) V.T。小的奇异值对应弱方向；在该方向求逆会放大需求与噪声。

条件数和奇异值要结合任务维度、单位、尺度与阈值。不是任何小奇异值都应套同一个报警数，也不能用 det==0 精确浮点判断所有情况。

阻尼可以抑制关节增量，但通常带来任务残差；仍需明确速度、限位和任务要求。

## 多个解与冗余分开看

2R 的两个肘部分支是离散多解，普通位置任务中仍可能局部满秩。若 n 个关节、任务雅可比秩为 r，则瞬时零空间维数为 n-r。

多余关节在非奇异任务中可以提供连续的姿态调整方向；限位和障碍会限制实际能用的方向。奇异点也可能出现瞬时零空间，不能因此直接把机构称作常规冗余机构。

Moore–Penrose 伪逆下，N=I-J⁺J 把关节方向投影到线性零空间。若换成阻尼近似逆，I-J#J 一般不再是精确零空间投影。

## 练习

<a id="ex1"></a>

### 第 1 题：秩降了，还能做什么？约 20 分钟

求 q=(0,0) 与 (0,π/2) 的秩、行列式和奇异值。说明前者怎样仍可沿 y 运动，为什么不能仅靠当前 J 实现非零 x 速度。

观察 q2=1e-3 rad 的条件数，区别“数学上满秩”和“数值上难处理”。

<a id="ex2"></a>

### 第 2 题：伪逆与阻尼的代价。约 25 分钟

取 q=(0,1e-3)，要求 xdot=(0.01,0) m/s。比较 pinv(J)@xdot 与 lambda=0.01 的阻尼速度解。

记录关节速度范数和 ||J qdot-xdot||。不把较小关节速度自动当作更准确完成任务，也不将大数值发送给机器人。

<a id="ex3"></a>

### 第 3 题：离散分支与连续零空间。约 20 分钟

比较 2R 目标 (0.3,0.2) 的两个肘部分支，与教学局部矩阵 J=[[1,0,1],[0,1,1]]。

后一个矩阵不是本章 2R 的 J，用于代表两项任务对三项变量的线性化。求其核的一条方向，说明它和“两个不同的肘部解”有何区别。

<a id="ex4"></a>

### 第 4 题：阻尼后还精确不影响主任务吗？选读约 25 分钟

对第 3 题矩阵，取 z=(0,0,1)。算 (I-pinv(J)@J)@z，并检验 J@结果。

再以阻尼近似逆替代 pinv，观察主任务是否仍严格为零。说明这都是局部线性结论，有限关节步还需 FK 检查。

## 直觉与回顾

末端速度集合像当前姿态提供的一组可用方向。伸直时它被压扁，某个方向再用力求解，也可能只换来很大的关节数值。

冗余则像完成同一任务仍留有姿态调整空间。复盘用一个秩或一个零空间向量证明自己的理解，避免只凭“有多个解”判断。
