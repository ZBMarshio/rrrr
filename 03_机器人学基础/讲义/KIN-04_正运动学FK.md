## 推导时先指出角度属于哪根杆

第一段方向相对基座为 q1，第二段相对基座为 q1+q2，因此：

```text
x = L1 cos(q1) + L2 cos(q1+q2)
y = L1 sin(q1) + L2 sin(q1+q2)
yaw = q1+q2
```

两根杆的向量在同一个基座坐标中相加。q2 是相对角，若错当作第二段的绝对角，某些零位仍会对，非零姿态就暴露问题。

同一结果也可由局部变换串起来：

```text
T_base_tool = RotZ(q1) @ TransX(L1) @ RotZ(q2) @ TransX(L2)
```

每个局部平移沿当时的连杆 x 轴；将所有平移都当作基座 x，会把弯曲的机构算成别的模型。

## 实现细节

- 明确函数返回 xy 位置，还是包含旋转的完整 T。
- q 的固定顺序为 joint_1、joint_2，单位 rad，长度 m。
- link2 的原点在第二关节，tool0 位于第二段末端，别查询错点。
- 工具偏置改变末端定义，必须进入变换链；不能只给最后结果随意加一个世界坐标常量。
- 用零位、非零角、参数变化分别检查；只测 q=[0,0] 不能识别很多错误。
- 两个实现若只是复制了同一行公式，不算很强的独立参照。手画、矩阵链、成熟库或模型可提供不同检查角度。

## 练习

<a id="ex1"></a>

### 第 1 题：三组姿态先手画。约 20 分钟

L1=0.3、L2=0.2 m，求 q=(0,0)、(π/2,0)、(0,π/2) 时的位置与 yaw。

画出第二关节位置和 tool0，说明两者为什么不同。

<a id="ex2"></a>

### 第 2 题：直接几何与变换链交叉核对。约 40 分钟

自己写 fk_xy(q)，输出 (2,)；另用局部旋转/平移矩阵连乘计算同一点。输入要求两项有限关节角与正的有限长度。

比较第 1 题与十组固定种子的角度。写下绝对位置误差和单位；有差异时先检查约定，不立即放宽容差。

<a id="ex3"></a>

### 第 3 题：故意把模型写错一次。约 20 分钟

分别试一个错误：第二段用 cos(q2)/sin(q2)；把 300 mm 写成 300 m；把 link2 原点当成 tool0。

为每个错误选一组最容易识别的输入，说明为什么只用零位会漏掉其中某些错误。

<a id="ex4"></a>

### 第 4 题：工具长度改变后会怎样？约 25 分钟

只将 L2 从 0.2 改为 0.25 m，预测任意姿态的末端位置变化向量。先画方向，再用程序验证。

W04 时将同一变化落实到 URDF/工具固定偏置，与 TF 对照；复用第二章成果，不重复搭环境。

## 直觉与回顾

FK 就是沿机构逐段走过去，每一段先看“它现在朝哪里”，再把这段长度加进去。复杂机构也在重复这种局部关系的组合。

能画出两个关节的位置，再说清末端多走了哪一段，比记住一个最终长公式更容易迁移。复盘写一处“局部方向”怎样变成“基座方向”。
