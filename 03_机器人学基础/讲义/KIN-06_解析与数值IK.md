## 解析方法先给一个可核对的参照

余弦定理决定 q2：

```text
c2 = (x²+y²-L1²-L2²)/(2 L1 L2)
q2 = atan2(±sqrt(1-c2²), c2)
q1 = atan2(y,x) - atan2(L2 sin(q2), L1+L2 cos(q2))
```

理想可达内部常有两个肘部解。得到候选后用 FK 代回，再查关节限位；只看 arccos 没报错不够。边界分支可能重合或有周期等价，要按关节类型处理。

## 数值方法是反复修正当前猜测

```text
输入：目标、初值、限位、容差、迭代上限
误差 e = target - FK(q)
用当前 J 求一个关节增量
限制步幅，尝试更新并检查误差
足够准确就成功；无进展/到上限则明确退出
```

一种阻尼最小二乘增量：

```text
dq = J.T @ solve(J @ J.T + lambda² I, e)
```

lambda>0 抑制接近奇异时的放大，但也会影响误差修正。它不是通用魔法数；本例 J 的量纲与位置误差固定，混合位置/姿态时还要处理尺度。

## 三种结论分开报告

| 结论 | 需要的依据 |
|---|---|
| 本次收敛 | FK 残差在容差内，限位满足，实际任务约束一致 |
| 本次停滞/迭代上限 | 给出目标、初值、参数、残差与历史 |
| 数学/约束不可达 | 需要几何、解析条件或其他足够证据；局部失败本身不够 |

一组初值失败，换初值可能成功。不要把失败状态统称为 unreachable；也不要循环到上限后照样返回 success。

## 练习

<a id="ex1"></a>

### 第 1 题：用两组解析解核对同一目标。约 30 分钟

对目标 (0.3,0.2) m 求两个候选，FK 代回并画图。再试 (0.7,0)，说明应怎样处理超过几何范围的 c2。

仅在舍入容差内才将 c2 截到 [-1,1]，不能把明显不可达目标硬裁成边界解。

<a id="ex2"></a>

### 第 2 题：自己实现二维数值 IK。约 60—90 分钟

先按流程写函数，依赖已有 fk_xy/jacobian_xy：初值、目标、限位、容差、迭代上限；记录每次位置残差。限制单步，若更新变差可减小步长再试。

输出 q 与 success、reason、iterations、residual、history。初期先在普通可达目标运行，再加入坏输入与失败退出。

<a id="ex3"></a>

### 第 3 题：同一目标，不同初值和限制。约 30 分钟

比较：

1. target=(0.3,0.2)，q0=(0.2,0.2)；
2. target=(0.45,0)，q0=(0,0) 与 (0.1,-0.2)；
3. target=(0.7,0)；
4. target=(0.3,0.2)，q2 限在 [-1,1]。

为每项记录结果。特别解释第 2 项为什么几何可达却可能停滞，第 4 项用解析条件说明约束。

<a id="ex4"></a>

### 第 4 题：位置到了，朝向就一定对吗？约 20 分钟

仍取 (0.3,0.2)，现在又要求 yaw=0。看两个解析候选的 yaw，判断原来的位置 IK 是否完成了新任务。

再说清工具/TCP 改变时应改哪份 FK；不要拿一个末端的 IK 结果当成另一个工具点的位置保证。

## 直觉与回顾

数值 IK 像站在当前位置，用局部地图选择下一小步。初值决定从哪里出发；奇异处的小地图可能不给出你想走的方向。

一份诚实的失败记录可以帮助你分清“路不好找”和“任务根本不满足条件”。复盘选一次失败，用残差和几何解释它，而不是只写“多试几次就好了”。
