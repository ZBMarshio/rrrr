## 先用一轴旋转建立感觉

```text
Rz(theta) = [ cos(theta) -sin(theta)  0 ]
            [ sin(theta)  cos(theta)  0 ]
            [     0           0      1 ]
```

按本章列向量与右手系约定，theta=π/2 时，+x 变到 +y。合法旋转满足 R.T R=I、det(R)=+1；反射矩阵也可能正交，但不是这里的旋转。

完整位姿包含旋转和位置。T 的最后一列上三项是平移，旋转不能只取那三个数，位置也不能从旋转角直接得到。

## 四元数先抓四个事实

- 单位四元数才能直接代表旋转；零四元数无效。
- 本章与常见 ROS/SciPy 默认顺序采用 (x,y,z,w)，别的接口可能不同。
- q 与 -q 表示相同旋转，不能只用原始四维差值判断姿态误差。
- 四元数四个分量受单位范数约束，不代表物体有四个独立旋转自由度。

SciPy 会对非零输入归一化；你的接口仍应明确是否允许并记录归一化，不让严重坏数据静默变成“正常姿态”。

## 细节

- 函数输入用 rad；想从度转换时显式 deg2rad 或 radians。
- Euler 角必须说明轴顺序、内/外旋、角度单位。三轴旋转一般不交换。
- 欧拉角在某些姿态会有表示奇异，和机械臂自身的雅可比奇异不是同一个问题。
- 正交性验证只检验表示形式；朝向是否符合实际仍要用轴与点检查。
- 测小姿态误差时浮点精度与容差有影响，别为一个理想例子通过就声称真实安装准确。

## 练习

<a id="ex1"></a>

### 第 1 题：90° 与 π/2，以及先后顺序。约 20 分钟

自己实现 Rz(theta)，预测 Rz(π/2)@[1,0,0]。比较把 90.0 直接当 rad 的结果。

再取 Rx(π/2) 与 Rz(π/2)，分别计算 Rz@Rx@[0,1,0] 与 Rx@Rz@[0,1,0]，说明为什么不同。

<a id="ex2"></a>

### 第 2 题：四元数整体换符号。约 20 分钟

绕 z 正转 90° 的四元数按 x,y,z,w 写出。用成熟实现转换 q 和 -q，比较旋转矩阵，再看直接相减是否为零。

用零四元数测试拒绝行为。有 SciPy 就用已有环境；没有时先做手算，转换运行另记待验证。

<a id="ex3"></a>

### 第 3 题：给位姿矩阵做基础检查。约 25 分钟

写 is_rigid_transform(T)：形状 4×4、有限数、末行正确、R 正交且 det≈1。测试正常 T、含缩放的 R、反射 diag(1,1,-1)、坏末行和 NaN。

比较为什么仅检查 R.T@R≈I 还不够。

<a id="ex4"></a>

### 第 4 题：179° 与 -179° 相差多少？约 20 分钟

两个绕 z 的姿态分别为 179° 与 -179°。比较直接减角得到的结果与最小旋转角差，写一个由旋转矩阵计算角度误差的函数。

说明这用于表示差异；有机械限位的关节是否能走最短绕行路径，要到 KIN-03 单独检查。

## 直觉与回顾

旋转矩阵像三根新坐标轴的方向说明，四元数是另一种紧凑编码。编码不同，物体的朝向可以完全一样；q 与 -q 就是提醒你“比较编码”和“比较物理姿态”有区别。

把一个向前的箭头转一次，再核对矩阵的列，比一开始背所有 Euler 角公式更容易建立感觉。复盘用一个实际箭头解释你的符号和顺序。
