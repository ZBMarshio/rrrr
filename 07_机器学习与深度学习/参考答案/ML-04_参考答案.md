## 第 1 题

```python
from torch import nn

class FKRegressor(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 32), nn.Tanh(),
            nn.Linear(32, 32), nn.Tanh(),
            nn.Linear(32, 2))

    def forward(self, x):
        return self.net(x)
```

参数为 96+1056+66=1218，线性基线为 6。无激活时，多个仿射变换的复合仍是仿射变换；中间有 Dropout 等其他操作时需另论，这里只讨论普通线性层复合。

## 第 3 题

```python
class TinyCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(8, 16, 3, padding=1), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(16, 2))

    def forward(self, x):
        return self.net(x)
```

形状：`[B,8,16,16]→[B,8,8,8]→[B,16,8,8]→[B,16,1,1]→[B,16]→[B,2]`。参数 80+1168+34=1282。池化/激活没有可训练参数。

## 第 4 题

标签要平衡；训练和验证用不同随机种子生成，不复制同一图。改变方向之外的位置/亮度，先画样本确认标签含义。分类准确率按总样本统计，同时看横→竖和竖→横两类错误。

训练前 `logits.shape==(B,2)`，`label.shape==(B,)` 且 dtype=long；`nn.CrossEntropyLoss()(logits,label)`。验证要 eval+no_grad。合成条纹高准确率证明小型分类流程可用；真实物体、复杂背景和相机域的能力仍需相应数据验证。
