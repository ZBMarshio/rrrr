## 第 2 题

可用局部 NumPy RNG，特征 `session_id+U(-.01,.01)`，每回合固定一个随机目标。逐帧：每回合偶数帧 train、奇数帧 val；分组：session0—7 train、8—11 val。

```python
import numpy as np

def nearest_value(x_train, y_train, x_query):
    x_train, y_train, x_query = map(np.asarray, (x_train, y_train, x_query))
    if x_train.ndim != 2 or x_query.ndim != 2 or x_train.shape[1] != x_query.shape[1]:
        raise ValueError("feature matrices must match")
    if len(x_train) == 0 or y_train.shape != (len(x_train),):
        raise ValueError("nonempty paired scalar targets required")
    if not all(np.isfinite(a).all() for a in (x_train, y_train, x_query)):
        raise ValueError("finite data required")
    index = ((x_query[:, None, :] - x_train[None, :, :])**2).sum(axis=-1).argmin(axis=1)
    return y_train[index]
```

逐帧时邻居来自同一个 session，目标相同，误差接近零；分组时没有见过该 session 的随机目标，误差增大。数值取决于种子；这个构造说明两种划分回答不同问题，不证明所有实际数据的分组误差必定更大。

## 第 4 题

```python
def assert_disjoint_groups(train_ids, val_ids, test_ids):
    groups = [set(train_ids), set(val_ids), set(test_ids)]
    if any(not g for g in groups):
        raise ValueError("nonempty split groups required")
    if groups[0] & groups[1] or groups[0] & groups[2] or groups[1] & groups[2]:
        raise ValueError("group leakage")
    return True
```

文件复制、裁剪、增强、同回合不同帧可以文件名不同但来源相关。先分组再切窗/增强；检查每个窗口的全部原始 frame_id，而不只最后一帧。该函数只核对传入的 group，无法自动发现错误的分组定义。
