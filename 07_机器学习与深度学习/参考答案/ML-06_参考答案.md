## 第 2 题

```python
import math
import torch

def manual_attention(q, k, v, allowed):
    if q.ndim != 3 or k.ndim != 3 or v.ndim != 3:
        raise ValueError("B,L,D tensors required")
    b, length, dim = q.shape
    if min(b, length, dim, k.shape[1], v.shape[2]) < 1:
        raise ValueError("nonempty dimensions required")
    if k.shape[0] != b or k.shape[2] != dim or v.shape[:2] != k.shape[:2]:
        raise ValueError("incompatible Q/K/V shapes")
    if allowed.shape != (b, length, k.shape[1]) or allowed.dtype != torch.bool:
        raise ValueError("boolean allowed[B,L,S] required")
    if len({q.device, k.device, v.device, allowed.device}) != 1:
        raise ValueError("same device required")
    if q.dtype != k.dtype or q.dtype != v.dtype or not q.is_floating_point():
        raise ValueError("matching float dtype required")
    if not all(torch.isfinite(x).all() for x in (q, k, v)):
        raise ValueError("finite Q/K/V required")
    if not allowed.any(dim=-1).all():
        raise ValueError("each query needs at least one allowed key")
    scores = (q @ k.transpose(-2, -1)) / math.sqrt(dim)
    weights = scores.masked_fill(~allowed, float("-inf")).softmax(dim=-1)
    return weights @ v, weights
```

对照 SDPA 时增加单头维：`q[:,None]`、`k[:,None]`、`v[:,None]`，mask 为 `allowed[:,None]`，dropout_p=0；再取结果 `[:,0]`。本函数只用于小型 float32/64 学习核对，没有实现高效内核与 AMP 数值策略。

## 第 3 题

causal allowed 为下三角（包括对角）；修改未来 K/V，不影响只能读取过去/当前的 query。原始 SDPA 只做点积注意力；MultiheadAttention 还会做输入/输出投影，不能未经参数对齐就逐值比较两者。

`nn.MultiheadAttention(embed_dim=8,num_heads=2,batch_first=True)` 的布尔 attn_mask 使用 `~allowed[0]`（所有 batch 相同 mask 时）。可通过其返回的注意力权重检查上三角为零。Transformer 层还加了 FFN、残差与归一化，维度相同并不意味着功能相同。

## 第 4 题

```python
def masked_mse(pred, target, valid):
    if pred.ndim != 3 or pred.shape != target.shape or pred.shape[-1] < 1:
        raise ValueError("equal B,T,A predictions/targets required")
    if valid.shape != pred.shape[:2] or valid.dtype != torch.bool:
        raise ValueError("boolean valid[B,T] required")
    if pred.device != target.device or pred.device != valid.device:
        raise ValueError("same device required")
    if pred.dtype != target.dtype or not pred.is_floating_point():
        raise ValueError("matching floating dtype required")
    if not valid.any():
        raise ValueError("no valid targets")
    p, y = pred[valid], target[valid]
    if not torch.isfinite(p).all() or not torch.isfinite(y).all():
        raise ValueError("finite valid values required")
    return (p - y).square().mean()
```

先选择有效值，避免 NaN×0 仍为 NaN。分母为有效 token 数×A；若各动作维物理尺度不同，需先明确归一化/加权规则。causal mask 是 query×key 关系，不是某个输出是否有标签；两者不能直接互换。
