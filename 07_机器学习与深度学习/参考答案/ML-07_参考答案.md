## 第 2 题

```python
import math
import torch
from torch.nn import functional as F

def symmetric_contrastive_loss(image_features, text_features, temperature=0.1):
    a, b = image_features, text_features
    if a.ndim != 2 or a.shape != b.shape or min(a.shape) < 1:
        raise ValueError("equal nonempty N,D features required")
    if a.device != b.device or a.dtype != b.dtype or not a.is_floating_point():
        raise ValueError("matching floating dtype/device required")
    if not math.isfinite(temperature) or temperature <= 0:
        raise ValueError("positive finite temperature required")
    if not torch.isfinite(a).all() or not torch.isfinite(b).all():
        raise ValueError("finite features required")
    if not (a.norm(dim=1) > 0).all() or not (b.norm(dim=1) > 0).all():
        raise ValueError("nonzero feature vectors required")
    logits = F.normalize(a, dim=1) @ F.normalize(b, dim=1).T / temperature
    labels = torch.arange(len(a), device=a.device)
    return (F.cross_entropy(logits, labels) + F.cross_entropy(logits.T, labels)) / 2
```

用 I3 作为两组特征，正确对角配对损失很小；循环移位文本而保持 labels 不变，损失升高。N=1 时 softmax 只有一个候选，交叉熵恒为 0。这只是对比目标的玩具核对，没有训练图文模型；批内相似度也不是开放世界成功概率。

## 第 3 题

```python
def freeze_backbone(backbone):
    backbone.requires_grad_(False)
    backbone.eval()
    return backbone
```

只把 head 参数传给 optimizer；固定特征前向可在 no_grad 中做，再将 features 输入 head。外层 model.train() 后重新 backbone.eval()。该实验核对更新范围，不验证预训练迁移效果；随机初始化的固定特征不能冒充预训练模型。
