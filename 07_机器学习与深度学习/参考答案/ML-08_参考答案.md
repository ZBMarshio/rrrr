## 第 2 题

xt=0.8×2+0.6×1=2.2。下面 alpha_bar 是每个样本已按时间表查出的累计系数，不是单步 alpha。

```python
import torch

def q_sample(x0, noise, alpha_bar):
    if x0.ndim < 1 or x0.numel() == 0 or x0.shape != noise.shape:
        raise ValueError("equal nonempty batched tensors required")
    if alpha_bar.shape != (x0.shape[0],):
        raise ValueError("one alpha_bar per sample required")
    if len({x0.device, noise.device, alpha_bar.device}) != 1:
        raise ValueError("matching device required")
    if x0.dtype != noise.dtype or x0.dtype != alpha_bar.dtype or not x0.is_floating_point():
        raise ValueError("matching floating dtype required")
    if not all(torch.isfinite(x).all() for x in (x0, noise, alpha_bar)):
        raise ValueError("finite values required")
    if not ((alpha_bar >= 0) & (alpha_bar <= 1)).all():
        raise ValueError("alpha_bar in [0,1] required")
    a = alpha_bar.reshape(-1, *([1] * (x0.ndim-1)))
    return a.sqrt()*x0 + (1-a).sqrt()*noise
```

alpha_bar=1 时是 x0，0 时是 noise。加噪样本可以超出干净数据范围；不能据此直接下发机器人。

## 第 3 题

位置 -0.25，速度 3；步长 0.25，四步为 -0.25、0.5、1.25、2。

```python
def straight_flow_pair(noise, data, t):
    if noise.shape != data.shape or noise.ndim < 1 or noise.numel() == 0:
        raise ValueError("equal nonempty batched tensors required")
    if t.shape != (len(noise),):
        raise ValueError("one time per sample required")
    if len({noise.device, data.device, t.device}) != 1:
        raise ValueError("matching device required")
    if noise.dtype != data.dtype or noise.dtype != t.dtype or not noise.is_floating_point():
        raise ValueError("matching floating dtype required")
    if not all(torch.isfinite(x).all() for x in (noise, data, t)):
        raise ValueError("finite values required")
    if not ((t >= 0) & (t <= 1)).all():
        raise ValueError("time in [0,1] required")
    time = t.reshape(-1, *([1] * (noise.ndim-1)))
    return (1-time)*noise + time*data, data-noise
```

这里的速度已知道 noise/data 配对，只验证单条条件路径的公式。推理时不知道目标 data；训练出的网络需要仅凭当前 x、t、条件预测速度，再数值积分。没有做这个学习过程，不能报告生成质量。

## 第 4 题

训练：先按 episode 划分→train 动作统计→采样轨迹/时间/噪声→条件编码→预测噪声或速度→按有效动作 mask 求损失。推理：条件编码→初始噪声→指定调度/ODE 过程→反归一化动作。

H/A 的语义、动作块执行几步、观测刷新、频率、限位、停止、延迟和闭环成功率属于机器人系统与第八章。张量 [B,H,A] 正确仍不能代替这些接口约定。
