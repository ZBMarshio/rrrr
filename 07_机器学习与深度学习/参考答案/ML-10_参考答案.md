## 第 1 题

坐标 MSE=25/4=6.25 mm²，TCP RMSE=√(25/2)≈3.5355 mm，平均欧氏误差=2.5 mm，最大=5 mm。用米输入时 MSE=6.25e-6 m²，其余长度指标分别除以 1000。

```python
import torch

def position_metrics(pred, target):
    if pred.ndim != 2 or pred.shape != target.shape or pred.shape[1] != 2 or len(pred) == 0:
        raise ValueError("equal nonempty N,2 positions in metres required")
    if pred.device != target.device or pred.dtype != target.dtype or not pred.is_floating_point():
        raise ValueError("matching floating dtype/device required")
    if not torch.isfinite(pred).all() or not torch.isfinite(target).all():
        raise ValueError("finite complete predictions/targets required")
    error = pred - target
    distance = error.norm(dim=1)
    return {
        "count": len(pred),
        "coordinate_mse_m2": error.square().mean().item(),
        "tcp_rmse_m": error.square().sum(dim=1).mean().sqrt().item(),
        "mean_distance_m": distance.mean().item(),
        "p95_distance_m": torch.quantile(distance, .95).item(),
        "max_distance_m": distance.max().item(),
    }
```

该函数对完整有效位置求误差，不会静默丢弃 NaN；缺预测要在上层记失败/缺失数，不能过滤后只报告好样本。
