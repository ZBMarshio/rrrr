## 第 2 题

两者广播成 `[3,3]`，差值矩阵为 `[[0,-1,-2],[1,0,-1],[2,1,0]]`，均方为 4/3，而不是 0。先显式统一成 `[B,1]`，不要依赖 loss 的广播。

```python
import torch

def checked_mse(pred, target):
    if pred.shape != target.shape or pred.numel() == 0:
        raise ValueError("equal nonempty shapes required")
    if pred.dtype != target.dtype or pred.device != target.device:
        raise ValueError("matching dtype/device required")
    if not pred.is_floating_point() or not target.is_floating_point():
        raise ValueError("floating point values required")
    if not torch.isfinite(pred).all() or not torch.isfinite(target).all():
        raise ValueError("finite values required")
    return (pred - target).square().mean()
```

这里有意采取严格接口，不覆盖自动混合精度的输入类型协商。以后使用 AMP，应先明确模型输出和损失的精度策略。

## 第 3 题

```python
def nhwc_to_nchw(x):
    if x.ndim != 4:
        raise ValueError("NHWC rank 4 required")
    return x.permute(0, 3, 1, 2).contiguous()
```

检查 `new[b,c,h,w] == old[b,h,w,c]`。C=1 时删除/插入这个长度为一的轴，线性元素顺序恰好未变，reshape 可能蒙混过关；C=2 时就会错位。

## 第 4 题

`torch.from_numpy(a)` 与可共享的 NumPy CPU 数组使用同一块存储；`clone()` 创建另一份 Tensor 数据。训练日志若要保留当时值，也要避免保存会被后续原地修改的引用。

`cuda.is_available()` 为 False 时只完成 CPU 核对。CUDA 构建版本、驱动可用性、设备内存是不同信息。

迁移顺序为：创建模型→model.to(device)→创建 optimizer→搬每批 x/y→前向/反向。检查 `next(model.parameters()).device`、`pred.device` 和参数的 grad.device。CPU 的 NumPy 共享实验与 CUDA 拷贝是两件事：搬到 GPU 后不会继续使用 NumPy 那块 CPU 存储。
