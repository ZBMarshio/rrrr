## 第 1 题

初始误差 [-1,-3]，L=5；梯度 w=-7、b=-4。SGD 后 w=0.7、b=0.4，预测 [1.1,1.8]，新 L=0.725。

若 x、y 分别有单位 X、Y，则 w 为 Y/X、b 为 Y；L 为 Y²，∂L/∂w 为 X·Y。数学上的学习率与参数化、量纲有关，不能把所有量的同一数值学习率视为等效物理更新。

## 第 2 题

```python
import torch

def scalar_gradient_check(h=1e-6):
    if not 0 < h < 0.01:
        raise ValueError("small positive step required")
    x = torch.tensor([1., 2.], dtype=torch.float64)
    y = torch.tensor([1., 3.], dtype=torch.float64)
    w = torch.tensor(0., dtype=torch.float64, requires_grad=True)
    b = torch.tensor(0., dtype=torch.float64, requires_grad=True)
    loss = ((w*x + b - y)**2).mean()
    loss.backward()
    def value(ww, bb):
        return ((ww*x + bb - y)**2).mean().item()
    fd_w = (value(h, 0.) - value(-h, 0.)) / (2*h)
    fd_b = (value(0., h) - value(0., -h)) / (2*h)
    return loss.item(), w.grad.item(), b.grad.item(), fd_w, fd_b
```

重新前向再 backward、不清零，会在当前 grad 上累加。两次相同初始计算得到 [-14,-8]。每次独立更新前 `optimizer.zero_grad(set_to_none=True)`；有限差分精度不总是 h 越小越好。

## 第 4 题

| 模式 | Dropout | 前向记录梯度图 |
|---|---|---|
| train + 默认梯度 | 随机屏蔽 | 对需要梯度的路径记录 |
| eval + 默认梯度 | 关闭随机屏蔽 | 仍可记录 |
| train + no_grad | 仍随机屏蔽 | 不记录 |
| eval + no_grad | 关闭随机屏蔽 | 不记录 |

用固定多元素输入多次比较；一次偶然相同不足以证明随机层关闭。参数冻结还需 `requires_grad_(False)` 或明确不更新，见 ML-07。

观察输出 requires_grad 时，用 Linear+Dropout 组合做实验：eval 下单独的 Dropout 可能直接返回原输入；no_grad 不会把那个已有输入的 requires_grad 改成 False。要区分“没有记录新的运算图”和“已有张量是否标记需要梯度”。
