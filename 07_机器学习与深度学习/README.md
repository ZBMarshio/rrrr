## 本章导读

**为什么学这一章。** 训练程序能启动之后，真正需要独立判断的是：模型学什么、梯度有没有更新正确参数、验证结果能支持什么。这章让一次小训练从输入到报告都能被解释。

**学完会有什么变化。** 学习前，可能主要跟着loss和显存占用判断进展；学习后，你能检查数据、维度、计算图、更新、恢复与泛化，把训练失败拆成可验证的问题。

**接下来能做什么。** 可以组织小型监督实验，形成CNN与注意力的基本认识，再把同一套工程用于BC、价值网络或动力学学习。预训练与生成模型按研究问题进入。

## 理论、代码与可验收成果

| 类型 | 当前要求 |
|---|---|
| 理论学习 | 理解损失、优化、泛化和网络表征；用张量维度追踪模型的数据流。 |
| 代码实践 | 自己写小型训练循环；做小样本过拟合检查，再加入验证、恢复和评测。 |
| 小项目/验收 | 一份可复现训练报告，包含曲线、数据划分、配置、错误分析和模型恢复验证。 |

无真机替代：小型回归、分类和状态策略可用 CPU；视觉与更大模型先测 4060 Laptop 的显存和吞吐。

本机已有完整 GPU 学习路径：先 FP32 训练与设备核对，再用 ML-03/09 学 CUDA RNG、scaler 恢复和资源测量。CPU 替代与原有前两阶段选学范围保留，学习者进度仍由自己的实现/验收填写。

成果尽量复用到总路线的项目版本中；运行成功、指标验证和硬件验证分别记录。
