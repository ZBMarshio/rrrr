# ML-05：先定位失败，再增加模型

## 导读

**为什么学这一节。** 训练变好、实际效果仍差时，加模型不一定能回答问题。先找到失败发生在数据、更新还是分布上，才有明确下一步。

**学完会有什么变化。** 从看到曲线就凭经验改超参数，进到会检查样本、梯度与参数变化，用小样本和分组验证区分候选原因。

**接下来能做什么。** 可以诊断自己的监督训练和[LEARN-02](../../08_机器人学习与具身智能/导读.md#learn-02)的BC数据问题，为[ML-10](ML-10_泛化评测与实验记录.md#intro)提供有依据的错误分析。

## 资料与范围

选读 [D2L 模型选择、欠拟合与过拟合](https://zh.d2l.ai/chapter_multilayer-perceptrons/underfit-overfit.html)，复用 [EXP-01 数据划分](../../00_公共基础与学习方法/知识索引.md#exp-01)。正则化先理解 weight decay、早停、数据增强的目的，暂不穷举所有技巧。

## 排错按证据推进

先看一批原始数据和标签：样本是否配对、顺序/单位/时间是否正确、是否出现 NaN。再看 forward 形状与初始 loss；然后确认梯度和参数变化；再用 16 个固定样本拟合。最后讨论数据量、容量、正则化与分布差异。

| 现象 | 优先排查 |
|---|---|
| train/val 都不下降 | 输入/标签、断图、未 step、学习率、归一化、loss 定义 |
| train 好、val 差 | 划分、分布差异、容量与正则化、val 模式/预处理 |
| val 极好、换回合失败 | 相邻帧泄漏、同场景记忆、验证问题与部署问题不一致 |
| loss 降、动作效果差 | 单位/字段/时间、离线目标与闭环任务差距；接第八章 |

这些是排查方向，不是凭曲线自动定因。一次只改一个条件，留下变更与结果。

## 机器人数据特别容易遇到的划分问题

同一回合相邻帧高度相关。若训练/验证都含同一回合，测到的可能是该回合插值能力；若目标是新场景/新物体泛化，应按相应 episode/session/object 划分，且滑动时间窗不能跨集合。

“按回合划分”也不是万能：同一物体、相机配置或采集日仍可能跨集合。划分单位取决于你要回答什么问题。增强、归一化、筛样、早停和超参数选择同样不能偷用最终测试信息。

## 练习

<a id="ex1"></a>

### 第 1 题：故意造成失败。约 30 分钟

在小训练里依次遗漏 step、断开预测梯度、打乱标签配对。记录 loss、梯度范数、参数变化。哪种情况下 loss 可能仍下降？不能仅凭“会下降”判定正确。

<a id="ex2"></a>

### 第 2 题：两种验证回答什么。约 30 分钟

构造 12 个 session、每个 20 个近重复帧。每个 session 有随机目标值，特征是 session_id 加极小抖动。比较逐帧分割和整 session 分割下的 1NN 误差，画集合成员表。1NN 只是泄漏演示，不是本章网络基线。

<a id="ex3"></a>

### 第 3 题：正则化对照。约 35 分钟

固定主项目数据和 MLP，比较 weight_decay=0 与 1e-3。保持更新预算与初始化相同，只看 val 作选择。结果未改善时如实记录，不能为得到“理论正确”的结论换测试集。

<a id="ex4"></a>

### 第 4 题：带 ID 的划分检查。约 25 分钟

写一个集合检查函数，确认用于独立泛化评测的 train/val/test group ID 互不重叠。把滑动窗 [t−2,t] 的原始帧归属考虑进去。只检查文件名是否相同，为什么不够？

## 直觉与回顾

验证集是一张考卷，划分规则决定题目究竟考了什么。分数低可以指导改进；题目和目标不一致时，分数再高也很难指导下一步。

复盘：你现在的 val 究竟在测新帧、新回合、新物体，还是新任务？
