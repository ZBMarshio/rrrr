## 导读

**为什么学这一节。** 同一观测可能对应多种合理动作，单一平均值未必合适。概率生成方法帮助你思考输出分布及其采样过程。

**学完会有什么变化。** 从把扩散和流匹配只理解为逐步改进结果，进到能说明网络预测噪声还是速度，区分训练目标、时间与推理采样。

**接下来能做什么。** 可以核对加噪和路径公式，再阅读[LEARN-04](../../08_机器人学习与具身智能/导读.md#learn-04)的生成动作策略，检查动作条件、尺度与执行窗口。

## 资料与范围

数学补 [MML](https://mml-book.github.io/) 第 6 章中条件分布、期望与高斯。选读原论文 [DDPM](https://arxiv.org/abs/2006.11239) 的前向加噪、简化噪声预测目标与采样算法，以及 [Flow Matching](https://arxiv.org/abs/2210.02747) 的条件路径与速度场训练思想。

本节了解机制，做公式与维度核对；完整生成模型、ODE 求解器与机器人生成策略到需要时深入，不列为前两阶段要求。

## 三件事不要混为一谈

1. 确定性回归输出一个值；在平方误差下，理想解趋向条件均值。
2. 概率模型描述多种可能输出及其条件关系。
3. 训练目标与推理采样是两个流程，采样步数和调度器也属于方法配置。

若相同观测的动作标签可能为 -1 或 +1，均值 0 的 MSE 最小，但 0 未必是合理模式。不是说所有回归都会失败，而是要看数据是否存在当前输入无法区分的多模态。

DDPM 常用：

$$x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\quad
L=E\|\epsilon-\epsilon_\theta(x_t,t,c)\|^2.$$

网络看含噪样本、时间与条件 c，学噪声预测；推理按相应调度反向多步生成。不能把预测噪声直接当干净动作，也不能随意混用不同模型的时间定义与 scheduler。

一个便于理解的流匹配条件直线路径：

$$x_t=(1-t)x_{\text{noise}}+t x_{\text{data}},\quad
u_t=x_{\text{data}}-x_{\text{noise}}.$$

网络学习条件平均速度场，推理从噪声积分。这里把 t=0 定义为噪声端；其他实现可能不同。单个已知样本对的直线不是训练后的总体流。

## 练习

<a id="ex1"></a>

### 第 1 题：平均值为什么会尴尬。约 20 分钟

标签等概率为 -1、+1，求常数预测 a 的期望 MSE 与最优 a。若这是绕障碍左右两条路径中的一个动作，这个例子提示了什么，又没有证明什么？

<a id="ex2"></a>

### 第 2 题：加噪公式。约 25 分钟

给定 x0=2、epsilon=1、alpha_bar=0.64，求 xt。实现按 batch 广播的 q_sample；检查 alpha_bar=1 与 0 的端点。实际离散训练调度不一定包含这两个精确端点。

<a id="ex3"></a>

### 第 3 题：直线路径与速度。约 25 分钟

noise=-1、data=2、t=0.25，求位置与目标速度。从 -1 用已知常速度 Euler 积分四步到 t=1。为什么这还不能说“训练好了流匹配模型”？

<a id="ex4"></a>

### 第 4 题：准备接动作序列。约 30 分钟

假设条件为图像特征和状态，输出未来 [B,H,A] 动作。分别画扩散/流匹配的训练与推理流程，写出时间、条件、mask、动作归一化和反归一化的位置。哪些内容属于第八章的闭环执行问题？

## 直觉与回顾

生成过程可以理解为逐步把一个初始随机样本变成符合条件的答案。每一步看似简单，可靠性仍取决于训练分布、目标、数值过程和条件信息。
