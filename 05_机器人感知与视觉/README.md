## 本章导读

**为什么学这一章。** 机器人看见一个物体之后，仍要知道它在哪里、这个估计属于哪个坐标系和时刻，以及偏差有多大。这章把图像中的信息逐步变成可用于行动的空间量。

**学完会有什么变化。** 学习前，容易把检测框、深度和目标位姿当作同一种结果；学习后，你能解释每种观测提供了什么，核对相机与手眼参数，并用独立数据检查定位。

**接下来能做什么。** 可以完成从标记物图像到基座目标的链路，进一步接规划和模拟到达。自然物体模型、视觉伺服与触觉随后按任务增加。

## 学习内容与掌握层次

| 层次 | 内容 |

<a id="route"></a>

## 学习路线

1. 从图像与标记物开始学习相机模型，完成内参标定并检查未参与标定的数据。
2. 加入 PnP 或深度反投影，把目标转换到机器人基座坐标；学习眼在手上/眼在手外的区别。
3. 完成一种手眼标定流程和定位实验，再按任务引入检测、分割或点云。

## 理论、代码与可验收成果

| 类型 | 当前要求 |
|---|---|
| 理论学习 | 理解成像几何、变换方向和误差来源；区分像素误差与空间误差。 |
| 代码实践 | 实现图像/深度读取、标定、坐标转换和误差统计；先用容易验证的标记物。 |
| 小项目/验收 | 标定参数、独立验证数据、定位误差分布和失败案例；形成可复用定位组件。 |

无真机替代：公开棋盘格图像、录制 RGB-D 或虚拟相机；合成多姿态数据验证手眼数学，实际安装精度另测。

成果尽量复用到总路线的项目版本中；运行成功、指标验证和硬件验证分别记录。
