# VIS-05：深度数值要和它所属的像素一起解释

[学习指南](../学习指南.md) · [知识索引](../知识索引.md#vis-05) · [提示与答案](../参考答案/VIS-05_参考答案.md)

## 导读

**为什么学这一节。** 深度图让像素有机会落到三维，但一个整数或零值未必就是有效距离。深度的编码、对齐与所属相机同样重要。

**学完会有什么变化。** 从随手取框中心深度，进到能核对尺度、无效掩码、光轴深度与距离，并检查RGB和深度是否对应同一空间点。

**接下来能做什么。** 可以生成带来源和有效性的三维点，为[VIS-07](VIS-07_检测分割与定位接口.md#intro)的目标区域定位与后续几何感知提供输入。

## 资料与本期范围

W16 完成单位、无效值和一次反投影小例子。完整点云滤波/配准以后按任务学。

[REP-118 官方源码](https://github.com/ros-infrastructure/rep/blob/master/rep-0118.rst)区分沿光轴的米制浮点深度与规定的毫米制 OpenNI 原始格式；[MIT 几何感知](https://manipulation.mit.edu/pose.html)选相机、深度和点云表示。实际 SDK 原始整数的 scale 必须查设备/驱动，不能单凭 uint16 猜毫米。

## Z 与距离不是同一个量

本节深度 Z 沿相机 z 轴；反投影后到光心的距离是 sqrt(X²+Y²+Z²)，离主轴越远，二者差别越明显。

如果传感器给的是距离、视差或其他编码，应按相应模型转换。原始图还要明确畸变、有效范围与深度内参。

## 无效值不是位于光心的点

无返回、超量程、零值、NaN/Inf 等按接口定义处理。无效值需要掩码和失败原因，不把它转成合法的 0 米目标。空区域、玻璃/反光或遮挡会造成空间定位失败，即使 RGB 上检测框很好看。

可以在明确属于目标的区域取多个深度样本并检查分布；边缘混合前景/背景时，简单平均未必代表任何真实表面。中值也不能保证选中了目标。

## RGB 和深度同尺寸，不等于对齐

深度相机和颜色相机可以有不同内参、视点和采样时间。正确关系是：

`深度像素 → p_depth → T_color_depth → p_color → 颜色像素`。

这还会涉及遮挡、多个点竞争同一像素、空洞和时间偏差。硬件/驱动已做对齐时，按其输出的深度含义、内参和 frame 使用，不重复套原始几何。

## 点云首先是许多反投影点

逐个有效深度像素生成相机三维点，保留像素映射、有效掩码和坐标系。之后才谈体素降采样、离群点、法向、配准或融合；不要在失去单位和来源的 Nx3 数组上一路处理。

## 直觉与回顾

深度给了沿视线的尺度，但每个数仍有自己的相机、时刻和有效性。把它和 RGB 对错位置，会很精确地算出错误物体的点。
