## 导读

**为什么学这一节。** 相机能看到目标、机器人能报告工具位置，两套信息仍需要一个固定空间关系才能一起使用。手眼标定正是在估计这个连接。

**学完会有什么变化。** 从背眼在手内/手外的参数顺序，进到先画闭合坐标链，再检查安装假设、采样配对与姿态信息。

**接下来能做什么。** 可以用留出位姿检验相机—基座变换，把[VIS-04](VIS-04_标记物与PnP位姿.md#intro)的结果接到[CTRL-05](../../04_机器人控制与运动规划/讲义/CTRL-05_末端到达与轨迹跟踪.md#intro)或[SIM-04](../../06_仿真与系统集成/讲义/SIM-04_MoveIt模型场景与执行.md#intro)的目标输入。

## 资料与主线布局

读 [OpenCV calibrateHandEye](https://docs.opencv.org/4.6.0/d9/d0c/group__calib3d.html)的输入/输出、两种布局和运动条件。复用第三章的刚体逆与合法变换检查，不重学所有矩阵运算。

W17 默认相机固定在外部，板刚性固定于工具。图像给出 T_camera_board，机器人状态/FK 给出同一时刻 T_base_tool；要估计固定的 T_base_camera，并检查固定的 T_tool_board。

## 四帧关系写出来

简记：

`G_i=T_base_tool_i，C_i=T_camera_board_i`

`Y=T_base_camera，X=T_tool_board`。

每次采样都满足：

`Y C_i = G_i X`。

左边从板经相机到基座，右边从板经工具到基座。同一块刚性安装的板、同一工具帧和配对时刻是方程成立的条件。

## 眼在手外怎样调用同一个函数

移项得到 `G_i⁻¹ Y C_i = X`，右边应固定。它和 API 内部“第一组变换 × 待求变换 × 第二组变换为常量”的结构对应。

因此本布局传入第一组 G_i⁻¹，即 T_tool_base；第二组仍是 C_i，即 T_camera_board，返回值解释为 Y=T_base_camera。API 参数名仍叫 gripper2base/cam2gripper，但本次坐标角色经过了重新对应。

不要只记“手眼就是把某组求逆”。若是眼在手上、板固定于外部，则是 `G_i T_tool_camera C_i=T_base_board`，可以直接使用原来的 G_i/C_i 角色。

## 姿态数量不是唯一条件

至少需要相应的非平行旋转运动来约束手眼关系；只有平移、几乎不转动或始终绕同一轴，可能不可辨识或病态。多张重复姿态不解决问题。

本章用相对旋转向量的奇异值做一个粗筛，不替代完整可观测性/条件数分析。第一阶段平面 2R 的单轴旋转不能默认满足三维通用标定。

采集时可先静止后配对，仍要核对图像时间、反馈时间、工具/TCP 与板坐标，及板是否松动。

## 怎样验收，而不是只看函数返回

1. 合成无噪声数据：恢复已知 Y，验证方向和单位。
2. 只在标定姿态上求 Y/X，冻结参数。
3. 留出姿态检查 `Y C_i` 与 `G_i X` 的位置和旋转误差。
4. 加噪声、错配时间或退化运动做对照，记录实际结果。

![手眼留出闭合的合成检查](/home/m/桌面/rrrr/05_机器人感知与视觉/图示/手眼闭合与错误配对.png)

生成器真值只用于生成/评分，不能直接进入实际感知/规划接口。合成通过不代表真实安装精度通过。

## 练习

<a id="ex1"></a>

### 第 1 题：推导并对照参数。约 25 分钟

画四帧图，推导 Y C_i=G_i X。分别写眼在手外与眼在手上的 API 第一组、第二组和输出含义。用一个板点验证乘法顺序。

<a id="ex2"></a>

### 第 2 题：三维合成标定。本周主要实践

自己指定已知 Y、X 和多组非共轴的 C_i，生成 `G_i=Y C_i X⁻¹`；预留若干姿态不参与求解。

先无噪声估计 Y，再给观测添加有单位的微小位姿扰动。说明这是配对位姿级合成，尚未模拟角点检测、关节/FK 与真实同步误差。

<a id="ex3"></a>

### 第 3 题：让错误暴露。约 30 分钟

分别试只有平移、同轴旋转、把 G_i 当作 G_i⁻¹、将部分 C_i 错配四种条件。记录异常或输出误差；不能仅因矩阵有限就算成功。

相机和板都固定在外部、机器人却随便运动时，原方程还成立吗？

<a id="ex4"></a>

### 第 4 题：冻结参数后看留出闭合。约 40 分钟

从标定集计算 Y 与 X 的代表估计，在留出姿态报告平移误差/m 与旋转误差/deg，保留逐样本值和汇总。

再将已估计的相机目标变为基座目标，并说明目标到工具接近位姿的固定偏置怎样接入。不要用标定板位姿直接替代所有抓取姿态。

## 直觉与回顾

同一块板可以沿两条坐标路径走到基座；标定是在找让两条路径持续一致的固定关系。拍到更多有信息量的姿态，就是给这套关系增加约束。

复盘拿一个留出姿态，把两边板原点和坐标轴画在一起。先让它们在数值上闭合，再把误差和安装条件带到真实平台。
