## 图像、投影与标定

| 检查 | 实际结果 |
|---|---|
| BGR/RGB 与索引 | 已知红像素转换一致，ROI 视图共享和 copy 独立行为符合预期 |
| 输入拒绝 | None、空图、灰度及不符合本节契约的浮点图被拒绝 |
| 裁剪/缩放 | 题设像素映射的新 K=[[300,0,140],[0,310,110],[0,0,1]]，示例点映为 (170,125.5) |
| 理想投影 | 手算与 cv.projectPoints 零畸变对照一致；同射线缩放保留投影，带 Z 反投影恢复点 |
| 无效几何输入 | 错误维度、非正或近零 Z 被拒绝 |
| 畸变反投影 | 三个测试点最大往返误差约 2.44e-9 m；忽略畸变约 0.009018 m。图示采用另一组 99 点，范围见图示说明 |
| 棋盘格顺序/单位 | 54 点的指定索引和 0.2×0.125 m 内角点跨度正确 |
| RMS 定义 | 两点残差长度 1/3 px 得 sqrt(5) px，与 norm/N 区分 |

相机标定对照采用本章 K/dist、18 个标定视图与 6 个留出视图、每轴 0.15 px 噪声，固定 k3=0。两组共享噪声样本与留出数据：

| 采集策略 | 全局标定 RMS/px | 六个留出逐图 RMS 的平均/px | 估计 fx/px |
|---|---|---|---|
| 较多样 | 0.209363 | 0.200254 | 600.229952 |
| 中央近正视 | 0.209421 | 1.815282 | 3896.803711 |

真实 fx=600 px。第二组虽然返回有限结果、训练误差也小，但参数和新视角明显不可靠。第一组带噪估计也未精确恢复所有真值：例如 cx≈324.744，而真值为 320；低重投影不等于参数或真实空间精度已充分验证。

无噪声的较多样数据能恢复 K，最大元素误差约 0.0000730 px；数据传给标定器时的 float32 精度也在误差来源内。独立用投影残差聚合得到的训练 RMS 与 API 返回相差小于 1e-4 px。

## 手眼方向、配对与留出闭合

用位姿级合成数据，18 组标定、6 组留出，固定外置相机布局。无噪声恢复 Y 的平移误差约 2.72e-16 m，留出最大闭合平移误差约 4.44e-16 m，反映理想数据的浮点数值自洽。

带噪观测的旋转向量每轴标准差 0.1°、平移每轴 0.0008 m；生成方式及真值见图示说明：

| 留出条件 | 平移闭合平均/最大/mm | 旋转闭合平均/最大/° |
|---|---|---|
| 正确配对、带噪位姿 | 1.97244 / 3.63259 | 0.109735 / 0.152822 |
| 同一估计，留出相机 ID 循环错位 | 172.264 / 360.472 | 50.8738 / 64.6164 |

带噪估计 Y 相对合成真值的平移误差约 0.441403 mm、旋转误差约 0.066474°；它与留出闭合是不同指标。

仅平移、同轴旋转被本题的旋转多样性粗筛拒绝。额外试验将 G_i 原样传入而非取逆，在此数据上产生了非合法刚体输出并被检查拒绝；其他错误输入仍可能产生合法矩阵，所以还需要留出闭合与独立验证。

本次没有角点→真实机器人 FK→手眼的完整实机链，也没有证明该旋转粗筛足以覆盖全部可辨识性问题。
